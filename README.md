# EasyRun · 裂隙 / 倒悬钟城

向下潜入旧城，借钩索穿过刺客与悬环，夺取钟心，再沿黑潮追来的井道向上逃离。

当前交付是 **v0.8.1 回声之城 · 每次技能刻印**：面向电脑浏览器和实体键盘的二维动作冒险单关，使用 XBuilder / spx 3.3.0。五种区域美术、四个可选机关和两种供能选择已进入主游戏。英语可在开场关闭；角色语音保持关闭，剧情通过环境短笺与纪事呈现。

**最新可玩代码在 `feat/inscription-v1`。** 本次整理沿用该分支，没有合入 `main`。五区的实际范围、选择后果和剩余内容见 [城市实现](docs/CITY_V08.md)，当前规则见 [PRD](docs/PRD.md)。四技能无冷却、每次释放均需答题；答错、拼错或超时直接取消。[交付清单](docs/releases/2026-10-25-v07-handoff.md)保留取消前的版本快照。

## 已实现的体验

| 系统       | 当前内容                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------- |
| 冒险       | 下潜、两道钟门、两阶段守心者、夺心返程、黑潮、结局、检查点和两档战斗难度                          |
| 城市与叙事 | 风钟门、铸钟炉、沉水档案、碎镜唱廊、守心机枢；风阀、升降台、档案肩台、镜桥；留灯 / 携心与条件结局 |
| 动作       | 跳跃、蹬墙、方向冲刺、钩索甩出、地面三连、空中追击、挑空、坠星、击退碰撞                          |
| 技能与敌人 | 贯夜 / 断潮 / 回息 / 五段连环剑刀；五类忍者刺客、控制反制、单练和组合排练                         |
| 铭文       | 拼写和三选一辨义；每局随机 30 词、预览、复习、独立难度与提示、本机词册                            |
| 连续性     | 战斗冻结保护与独立慢速表现；答案确认后立即接动作；每次四技能独立刻印；失败取消，无技能冷却        |
| 成就       | 15 项行旅 / 技艺 / 铭文成就，暗铜册页、最好进度、解锁日期、可佩戴称号                             |
| 声音与记录 | 82 个本地动作 / 材质采样与环境音乐；音量和减少动效设置；战绩、词册、成就分别导出                  |

30 词不是离场门槛，成就不增加战斗数值，排练场不记冒险成就。一次答对表示本次正确运用，不代表永久掌握英语。五区环境与机关已实装；十五房拓扑、语义机关、账号同步和付费未实装。

## 本地启动

需要 Git、Bash、curl、tar、校验工具和 Python 3。安装脚本支持 macOS / Linux 的 arm64 与 x64；当前主要本机验证环境为 macOS arm64。首次安装下载固定版本 Node、pnpm、spx 和测试浏览器。

```sh
git clone --branch feat/inscription-v1 https://github.com/RJ-SRE/EasyRun.git
cd EasyRun
bash scripts/bootstrap.sh
bash scripts/with-env.sh node scripts/build-game.mjs
bash scripts/with-env.sh node prototypes/runlab/server.mjs
```

打开 <http://127.0.0.1:4177/>。服务仅绑定本机，游戏无需账号、API 密钥或在线模型。当前协作预览使用 4184；端口只是启动参数，不是产品版本。更多安装、端口、专项检查、故障处理和导出方式见 [运行维护手册](docs/RUNBOOK.md)。

| 页面                | 用途                  | 构建方式                                                  |
| ------------------- | --------------------- | --------------------------------------------------------- |
| `/`、`/belfry.html` | 当前倒悬钟城主游戏    | `scripts/build-game.mjs`，或已有资源时 `build-belfry.mjs` |
| `/passages.html`    | 独立五通道 / 钩索实验 | 另运行 `prototypes/runlab/build-passages.mjs`             |
| `/rupture.html`     | 旧风机墓场            | 包含在 `scripts/build-game.mjs`                           |
| `/legacy.html`      | 最早两个对照原型      | 包含在 `scripts/build-game.mjs`                           |

## 操作

| 按键                        | 功能                                             |
| --------------------------- | ------------------------------------------------ |
| A/D、左右键                 | 移动、空中调整                                   |
| Space                       | 跳跃、二段跳、蹬墙                               |
| 按住 E / 松开 E             | 抓住高亮目标 / 借力甩出；方向键辅助选点          |
| K 或 Shift，配合 W/S        | 水平、向上或向下冲刺                             |
| J / W+J / S+J               | 普攻连段 / 挑空 / 坠星                           |
| 按住 U 或 L，松开           | 贯夜蓄箭 / 断潮蓄剑；短蓄与满蓄均需答题，无冷却  |
| I / Q                       | 回息 / 五段连环剑刀；答对才释放，无冷却          |
| F（机关旁） / V（机枢前厅） | 修复或留灯 / 携心；只在站稳且可交互时生效        |
| 顶部「城中纪事」            | 回看已抵达区域、修复发现与供能选择；主动打开暂停 |
| F（被缚索牵引时）           | 可选铭文解链；原有动作解法保留                   |
| 英文字母 / 1、2、3          | 拼写 / 选择中文释义；题中 Esc 打开铭文暂停面板   |
| S+Space                     | 下穿普通平台                                     |
| Enter / Esc / R             | 开始或续关 / 暂停 / 重开                         |
| T（标题或暂停）             | 进入排练；排练中 1–5 单类、6 组合，R 开始冒险    |
| 顶部「成就」                | 查看铭录、佩戴已解锁称号；题中暂不可打开         |

## 检查与交付边界

```sh
# 先构建；测试会自动启动并清理自己的随机端口服务
bash scripts/with-env.sh node scripts/test-game.mjs

# 四个游戏工程包；要求已经执行完整 game 构建
python3 prototypes/runlab/package.py
```

本轮技能规则与验证见 [测试记录](docs/TESTING.md) 最后一节；五区实机截图保留在城市测试记录。城市专项的测试场景与真实按键整关路线分别记录，历史结果保留原日期；本机通过不代表远程 CI 或真人体验已验收。

完整体验由网页宿主与 spx 共同组成。单独 `.xbp` 默认纯动作，不含网页铭文、成就册、本机存储或网页音频混音；独立通道没有合并进倒悬钟城的物理世界。尚未完成正式在线发布、完整编辑器往返导入、触屏 / 手柄、跨设备性能与真人长期体验验收。

源码、锁文件、原图、提示词和选定证据入库；`.tools`、依赖、缓存、拆帧、运行清单和导出包在本地保留或重建。旧版本与清理前历史均保留，没有伪造开发日期或用户数据。
