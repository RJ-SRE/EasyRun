## 设计判断

当前菜单的大标题、难度卡片和常驻设置表占据主要视线，缺少主角与环境之间的故事。新菜单表现一个具体瞬间：主角在高空断桥边整理装备，即将进入倒悬钟城。第一眼是角色与城市，第二眼是“进入钟城”，细项设置按需展开。

本轮建议采用“临风断桥”：通透的冷蓝云海、黑色石台、老旧铜构件、少量暖光和红围巾。与现有 C 封面共享角色和材质，但菜单使用新场景与不同构图。

可留作后续主题的两条方向：

- 余烬工坊：主角靠在维修台旁处理钩索，暖铜火光与冷色城市对照，适合剧情推进后的休整场景。
- 静水钟庭：主角蹲在浅水台阶边，倒悬城市映在水面，偏安静、神秘；倒影预先绘制，不要求实时反射。

三种主题共用相同功能位置和角色身份，不在首版同时制作。

## 主角动作设计

默认是侧坐在石台边，一只脚踏在台阶上，另一条腿自然垂下，身体略前倾。围巾被风吹向城市一侧。动作体现他在检查装备、观察目的地、准备行动。

| 情境           | 动作                                             | 节奏 / 约束                                                 |
| -------------- | ------------------------------------------------ | ----------------------------------------------------------- |
| 基础待机       | 胸背微呼吸；围巾与衣摆错相摆动；手指轻搭护腕     | 持续低幅度；脚底和臀部接触点固定，不把整张人物图左右摇晃    |
| 检查装备       | 低头，另一只手收紧腕部钩索，轻试收线，再松手     | 2.5–3.5 秒；手与护腕接触清晰，绳索有受力和回收过程          |
| 看向远方       | 面具抬起，视线移向远处塔尖，肩背稍转，再回到坐姿 | 2–3 秒；不用频繁看向玩家或反复点头                          |
| 风势增大       | 围巾先扬起，角色抬手压住衣领，松手后衣料回落     | 1.5–2.5 秒；衣料先受风，身体随后反应，避免全身同频摆动      |
| 偶发换姿       | 重心前移，起身到半蹲、轻试钩索，再坐回台沿       | 4–5 秒；低频出现，避免几秒一次循环表演                      |
| 指向“进入钟城” | 微抬头、手握住钩索柄，保持准备姿势               | 延迟约 150ms 响应；防止鼠标经过就频繁切动作                 |
| 点击开始       | 身体前倾起身，抛出钩索，向雾中出发，接入第一关   | 约 0.6–0.9 秒的可跳过过渡；点击立即生效，不必等当前待机结束 |

调度建议：基础待机为主，每 9–16 秒触发一次短动作；同一动作不连续抽取。一次 45 秒观察中至少有两种可辨认的行为。重置与切换菜单时回到明确的衔接姿势，不突然换成完全不同的朝向。

动作需要新绘制的坐姿、整理护腕和起身关键姿态。现有站姿风动可以借鉴衣料处理，但不能简单放大已有站姿来代替新动作，也不把概念图宣称为已经实现的动画。

## 场景与光线

近景是断桥石台与拱窗碎边；中景是主角、垂落锁链和可供出发的钩索方向；远景为向云海深处延伸的倒悬塔群。亮度由近暗到远明，保证角色轮廓和高度感。

只在面具、机械护腕、石台边缘与远方裂口使用暖色光。围巾是主要红色点缀，不铺满金色圆环或高亮粒子。背景变化包括缓慢漂移的两层薄雾、少量浮尘和局部链条摆动；整幅背景不做周期性缩放、左右摇晃或鼠标驱动的镜头晃动。

音乐沿用 v0.15.9 裁去前 5 秒的 Red Rock Riviera，默认 75%。菜单动作以视觉表达为主；不恢复此前已移除的钟鼓声，不添加角色语音。

## 设置收纳与功能保留

默认菜单直接提供开始、难度、铭文开关、本局词册、远征设置、排练、指南、声音入口。未删除现有能力：

| 现有功能                       | 新位置                                         |
| ------------------------------ | ---------------------------------------------- |
| 旅人 / 无畏                    | 主菜单直接切换；说明在选中项附近简短显示       |
| 铭文开启 / 关闭                | 主菜单一行开关                                 |
| 本局 30 词、预览、换组         | “本局词册”入口；换组放在词册内，关闭不自动换词 |
| 四级 / 六级 / 混合             | “远征设置”抽屉                                 |
| 从容 / 标准 / 紧凑             | “远征设置”抽屉                                 |
| 完整提示 / 2 秒渐隐 / 1 秒回忆 | “远征设置”抽屉                                 |
| 音乐、音效独立滑条             | 右下声音入口或设置抽屉；保留实时数值           |
| 排练、操作指南                 | 主菜单次级入口                                 |

设置抽屉在右侧原菜单范围展开，角色仍可见；Esc 先关闭抽屉，不退出标题。打开输入或搜索控件时隔离游戏快捷键。装饰人物、雾层不截获鼠标或键盘事件。开始时固定采用眼前预览的词册，不因角色动画或打开设置而重新抽取。

## XBuilder 与性能边界

以下是接入目标，尚未做本方案的运行性能测量：

- 角色使用单独的 MenuActor 状态，不驱动战斗 Hero，不启用敌人、伤害、物理或战斗特效；菜单不借用战斗震屏变量。
- 相机与 UI 固定。角色动作、局部衣料和环境层分别更新；改变造型 / 属性时才写入，避免整张菜单每帧重新栅格化。
- 背景预绘制为 2–3 层；活动浮尘目标上限 12 个，不用全屏高分辨率动画视频或实时模糊。
- 角色素材目标约 384×448、24–40 张关键帧并复用持帧，辅以少量独立衣料层。单层 40 张 RGBA 原始像素约 26.25 MiB，其他纹理与引擎开销另计；需测量实际峰值内存，超预算时减少帧数 / 层数。
- 展示帧率与姿势切换分离，使用 delta time 控制进度。低性能模式保留呼吸 / 围巾循环，停掉浮尘与偶发长动作；隐藏页面时停止菜单动画更新。
- 低动态偏好关闭随机长动作和出发动画，仍可直接开始游戏。进入游戏销毁 / 隐藏菜单专属层，避免两个场景同时更新。
- 继续使用完整视口适配，4:3 与超宽屏留边。窄窗口可使用紧凑控件布局，不能通过裁掉主角或按钮来填满屏幕。

## 接入顺序与验收

1. 锁定整体构图、标题和角色比例；准备无 UI 的背景分层、透明角色动作与独立标志。
2. 做坐姿待机和整理护腕的最小动态样片，先验证角色一致性、接触点、循环接缝与资源占用。
3. 接入新的菜单布局、设置抽屉和真实点击区域，分别验收网页与 `.xbp`。
4. 补齐随机短动作与出发衔接；菜单允许任何时候开始，不等待动画结束。
5. 固定相机连续采样，检查冷启动、悬停、设置开关、受击返回、死亡返回；静态 UI 坐标不抖动。性能在同一设备同一窗口与 v0.15.9 对比，分别报告常态、动作触发时与切换时的帧间隔和内存峰值。

美术验收：角色不换脸、不变服装、没有额外肢体；坐姿与石台接触可信；没有全身贴片平移冒充动作；标题明显缩小且位于左上；背景高度感清晰，设置可读。功能验收：所有原设置仍可找到；词册不被意外重抽；键盘输入不泄漏；暂停 / 结算返回稳定；循环音乐与默认音量保留。
