这些动作是后续动画建议，图片本身不含动画。正式实现仍需准备独立背景层、透明角色姿态和真实 UI 控件；镜头固定，动态由角色与少量环境层承担。水面方案可采用预绘制倒影与局部涟漪，风暴方案用云层和衣料表现风势，不需要全屏闪电或持续震屏。

三个方案均沿用收纳后的设置入口，不删除词库范围、作答节奏、提示难度、词册换组或独立音量。具体交互与性能验收沿用临风断桥设计文档。
