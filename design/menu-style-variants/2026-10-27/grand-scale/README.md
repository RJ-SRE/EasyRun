- 先确定选中的构图，再拆成背景、人物、局部动效和 UI；这些概念图没有动画，也不直接作为整张可交互菜单使用。

- 建筑保持稳定，云雾、围巾、局部水波缓慢运动；不恢复菜单震屏，不让整个场景反复缩放。
