通过实际 `.xbp` 的五段对照采样定位重复造型切换、文字广播、层级置顶与场景槽位查重。场景改用代际标记，渲染只提交变化，原生文字 / 层级按状态与镜头失效刷新；输入隔离只查实际被隔离的键，鼠标静止时省掉按钮扫描。UI 缓存过程中专门修正下拉悬停的绘制顺序，避免同一层级版本内二次置顶被缓存吞掉。

最终交付包经部署的 XBuilder 项目模型和编译器运行，衣料 4、单词 23、菜单 / 窗口 15，以及共享网页版场景 35 项回归通过。维持 121 个世界实例，原生观测克隆峰值 245 / 300。固定词册的旧 / 新对照显示词册帧间隔和页面任务耗时下降；战斗仍接近占满页面任务时间并存在长帧，完整数字和限制见 [本次验收](evidence/2026-10-27-idle-performance/README.md)。

性能计数、无敌和阶段切换仅注入测试副本；交付包 CRC 和音频 / 原动作注册配置通过核对。新增 24 张帧使压缩包增加约 2.84 MB。桌面交付 `EasyRun-XBuilder-v0.15.0-idle-performance.xbp`，旧版保留；未推送远程。

## 2026-10-26 · v0.14.0 原生拼写挑战补齐（仅本地）

复查确认此前原生版只做了视觉对齐，仍使用 Enter 结算，遗漏中文和渐隐提示。本轮将主拼写与有效变体统一逐字前缀校验，完整自动成功，首个不匹配字符直接调用原有技能取消逻辑；正确定义仍显示于题面，开始页新增三档提示选择。题目自己的时间控制渐隐，暂停不会消耗提示或重新泄露答案。

导出器同时隔离事件和 Hero 按键轮询：题目打开/结束捕获当前按键，各键真实松开后恢复。专项验证第一处错误字母（含正确前缀后的错误）取消 U/L/I/P，治疗退还资源，正确拼写及大写有效变体无需确认键释放，按住 W 不跳、按住 R 不重开。

题面缩为 400×138 / 400×148，拆分英文、中文、输入槽、底部提示；提示环随卡片缩小。实机截图发现标题下拉曾被异步文字穿透，改为等候文本图层完成再绘制下拉，复验后清晰显示。标题 SOUND 标题下移留出设置间距，声音通道和技能 HUD 无行为修改。

最终实际交付包运行 23 项单词与 15 项菜单/窗口测试，38 项通过；244 / 300 克隆峰值，418 个音频/HUD/技能/滑条资源哈希与上版一致。测试注入字段不进入交付包；桌面交付 `EasyRun-XBuilder-v0.14.0-spelling-challenge.xbp`，证据见 [验收](evidence/2026-10-26-native-spelling/verification.json)。不推送远程。

## 2026-10-26 · v0.13.0 原生铭文与界面（仅本地）

定位缺失原因是铭文内容和输入一直由网页宿主管理，而原生导出仅保留战斗侧关口。补充 NativeWords 主机，直接复用同一 8,815 词源，生成小尺寸 PNG 字形以避免中文字体依赖和每词大图片。原生范围明确为运行内记忆，未用无法保存的 UI 假装跨日存档。

将开始页拆为难度 / 主行动和远征 / 混音两区，缩小技能条并添加恢复环。舞台背景音乐和 NativeSfx 独立控制；动作 WAV 来源哈希在转码前核对。保留上一版镜头与 SVG 预渲染修复。

编译验收先发现空造型的声音精灵导致加载越界，改为透明占位图；真实拼写检查发现同一按键的重复 onKey 注册会吞掉 R/T 等字母，改为单个事件内按阶段分派。运行库 SetVolume(0) 实际会钳制到 1%，改为显式暂停 / 停止通道保证真正静音。固定字形池也会占满运行库 300 克隆预算，改成按需分配回收，将字形计入装饰效果预算，并增加场景实际出生数、箭矢实际出生数与总克隆上限断言。之后验证正确 / 错误 / 超时、四个技能和两类束缚、检查点和排练边界、两音轨隔离与窗口缩放。测试中准备资源、选择题型和设定束缚的按键只注入测试副本，不进入交付包。结果与实际测试包哈希见 [本次证据](evidence/2026-10-26-native-inscription/verification.json)。不改写在线项目、不推送远程。

## 2026-10-26 · v0.11.2 组合操作优化（仅本地）

## 2. 清理后的技术研究（2026-10-23）

问题：XBuilder 到底开放了哪些能力，能否承载成熟的二维动作游戏，底层引擎能力与编辑器入口有多大差距？

工作：固定编辑器提交和 spx 3.3.0，检查公开接口、源码与解释器导出；运行帧调度、动画、控制器、克隆上限、暂停和 AI 模块导入等微场景。

结果：12 个非短路径导入场景正常运行；一项 AI 短路径导入失败可复现；汇总中的 11 个断言通过。观察到全局运行时克隆上限为 300，隐藏克隆也占额度。自定义二维控制器、逐帧动画、透明效果、相机和有限克隆特效可用。没有证明完整实时灯光、GPU 粒子和骨骼动画工作流已开放。

取舍：先做短而明确的二维玩法，不把引擎扩展与大型内容生产同时纳入首版。报告中涉及英语/精灵的产品建议保留为当时语境，当前范围由新 PRD 覆盖。

证据：[技术报告](../research/xbuilder-boundaries/README.md)、其 `results/summary.json` 与原始探针结果。
