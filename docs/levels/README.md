# 回路遗迹：独立通道关卡

这是一段可以从开始菜单玩到结算的 spx 关卡，集中验证横向、下潜、攀升和墙体机关。入口为 **http://127.0.0.1:4177/passages.html**。原战斗入口与另一对话的敌人重构保持独立。

## 启动、检查与导出

在仓库根目录执行；已有依赖可直接使用。首次安装按仓库的 `scripts/bootstrap.sh` 配置 Node、pnpm 与 Chromium。

```sh
bash scripts/with-env.sh pnpm level:build
bash scripts/with-env.sh pnpm level:dev
# 浏览器打开 /passages.html
bash scripts/with-env.sh pnpm level:lint
bash scripts/with-env.sh pnpm level:test
bash scripts/with-env.sh pnpm level:package
```

本机 4177 已有服务器时直接打开入口，无需再运行 `level:dev`。测试使用独立随机端口，不重启正在试玩的服务。

`level:build` 从 Git 中的原始图集直接导入素材，不依赖战斗关卡生成的帧图。`level:test` 检查干净源码构建一致性，再用真实键盘完成生命周期和两种难度的路线。应在改动源码后先重新构建。导出的 `prototypes/runlab/exports/passages.xbp` 包含原生 spx 关卡；网页地图、音效、最佳成绩与菜单由独立网页外壳提供，不属于 xbp 编辑器工程的功能。

## 设计与实现

- `passages-level.mjs`：房间、平台、墙、锚点、活塞、遗物和重生点的统一几何数据。坐标 X 向右、Y 向上。
- `spx/passages/main.spx`：关卡进度、机关周期、检查点、暂停、失败及结算。五个机关状态依次为桥、左阀、右阀、配重、风阀。
- `spx/passages/Hero.spx`：连续速度、跳跃缓冲、离台宽限、墙跳、方向辅助钩索、墙体遮挡、平台携带与镜头。
- `build-passages.mjs`：图集导入、机械构件与关卡编译输入。生成项目文件、网页资源包与地图数据。
- `public/passages.*`：独立入口、地图、说明、机制状态、Web Audio 提示音、按难度区分的本机纪录。地图和说明在游戏中打开时会暂停。
- `test-passages*.mjs`：浏览器验收，不修改角色位置、机关状态或检查点以跳过路线。

| 机关       | 参数与恢复规则                                                                |
| ---------- | ----------------------------------------------------------------------------- |
| 墙环       | 450 单位范围内选点；接近 68 单位并持续牵引 0.6 秒触发；不能穿实体墙或关闭闸门 |
| 折叠桥     | 旅人 18 秒、试炼 12 秒；越过回廊检查点后保持通路；在入口失败会恢复初始机关    |
| 深井活塞   | 旅人周期 6 秒、试炼 4.6 秒；提前 0.8 秒显示轨迹；伸缩段 1.5 秒                |
| 两侧泄压阀 | 都开启后井底侧门解锁；失败保留已操作的阀门                                    |
| 配重台     | 上升 5 秒、停靠 6 秒、回落 5 秒；可重复拉环启动；本区重试会重置平台与开关     |
| 移动吊环   | 沿轨道往复 170 单位，两个吊环错相运动；下方有维修平台补救                     |
| 气流       | 开阀后周期 5.8 秒：预告 1 秒、上升 3.5 秒、休止 1.3 秒；两侧平台可以等待      |
| 遗物       | 八枚可选；检查点重试保留，R 从头重开清空                                      |

## 与敌人重构衔接

本模块没有敌人类型、旧剧情设定、战斗判定或击杀解锁条件；未改动 `spx/belfry/`、默认首页或敌人素材。它复用已存在的角色、建筑和平台原图，并在自己的导入目录生成帧图。

后续合并应由战斗入口消费 `passages-level.mjs` 中的数据和机关状态，沿用统一的世界坐标。主角物理更新顺序为「机关更新 → 平台携带 / 主角运动 / 碰撞 → 进度与危害 → 镜头」。只能有一个角色物理与相机驱动者，不能直接将两个 `Hero.spx` 同时启动。

敌人放置应避开出生安全区、拉环近身区域、活塞预警区、移动平台上下客位置以及必须经过的落点；战斗表现不应遮住机关预警。门的开闭仍由关卡机关决定，除非以后明确改需求。

## 当前范围

交付为一段完整的无敌人关卡与可扩展几何模块，尚未合入另一对话的战斗运行时。面向桌面键盘，手机展示操作提示，不包含触屏操控、联网、多关卡选关或线上排行榜。实际试玩节奏、八枚遗物全收集难度和不同设备表现仍需玩家测试迭代；自动通关结果不能代表商业验证。
