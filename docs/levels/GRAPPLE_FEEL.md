# 钩索氛围与反馈 · 2026-10-25

用户反馈当前钩索特效与音效不符合游戏设定，要求增强氛围。本次修改当前 `/passages.html` 入口，使钩索贴合持弦者与暗黑幻想遗迹的材质。另一对话的敌人、角色与战斗运行文件未改动。

## 视觉

原先的直接亮线改为有索头的细金属编索：射出时逐段展开，扣住时产生小范围铜屑与暖色余光，牵引时由松弛弧线逐渐绷紧，释放后用 0.16 秒回卷消失。索线起点跟随角色抬手位置，36 个复用索段沿弧线定向，停止时保留暂停姿态。

钩索不再生成连续的明亮人物残影，改为沿速度方向衰减的空气拖痕。固定锚点采用暗铜内壁和磨损边缘，选点由矩形准星改为收敛的破环提示。反馈集中于索头、索身和接触位置，不用大范围闪屏覆盖危险预告。

这些修改不改变钩索射程、牵引加速度、释放助推、跳跃、碰撞与机关时限。视觉射出阶段为 45–130 毫秒，移动响应仍立即发生。

## 声音

`public/passages-audio.js` 接替当前入口中固定音高的双振荡器提示音，使用仓库已有的 32 个材质采样与独立空间总线。采样是项目原创的程序化材质合成，**不声称为实物录音或真人表演**；来源仍见 `production/audio-v06/foley-log.json`，未重写原音频包。

| 阶段 | 游戏触发                 | 声音与空间                                               |
| ---- | ------------------------ | -------------------------------------------------------- |
| 射出 | `hook`                   | 短卡扣、抽索，偏干、贴近角色                             |
| 扣住 | `hookattach`             | 索头抵达后播放暗金属接触与少量铜腔余振，声像对应锚点     |
| 受力 | `hooktension` 与连续状态 | 绷弦采样；低声摩擦随速度、牵引强度和拉环进度变化         |
| 释放 | `hookrelease` / `sling`  | 短回卷与衣料、气流，跟随实际松手或自动甩出               |
| 环境 | 当前分区                 | 低声风隙底噪；深井和风塔的混响比例略高，近身瞬态保持清晰 |

空间采用约 31 毫秒预延迟、1.35 秒合成脉冲响应与低通尾响。没有角色声音、台词或新增背景歌曲。原来其余短提示也改为同一套衣料、铜腔和落地材质，避免钩索变得自然后仍被周围电子提示音打断。

单次音效最多并发 12 个，环境与索摩擦最多 2 条持续声轨。加载超过 220 毫秒的过期瞬态直接丢弃；暂停、失败、重开、静音和隐藏页面均会清理当前声源与空间尾响。恢复后按当前动作状态重建环境，不补播上一动作。
