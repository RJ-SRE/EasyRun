# 通道关卡开发记录 · 2026-10-25

## 已确认需求

用户要求丰富横向、下降、上升的通道，增加操作难度与墙体机关；明确要求不沿用旧敌人设定，因为敌人正在另一个对话重构。用户随后授权闭环开发。

## 本次实现

1. 建立独立数据、spx 模块、构建器、试玩入口与测试入口，避免写入另一开发过程的角色和敌人源码。
2. 将五个区域连接为可以完整通关的路线，加入桥、阀、活塞、配重台、移动锚点、气流、落脚点与八枚遗物。
3. 增加方向辅助钩索、释放助推、连续位移、跳跃缓冲、粗糙墙面蹬墙与平台携带；用双轴镜头覆盖三种通道方向。
4. 完成地图、暂停、操作说明、难度、检查点继续、失败与结算、本机记录及提示音。
5. 用真实浏览器键盘路线检查机关依赖、失败重试和通关，并保留状态与画面证据。

## 验证中修正

- 调整风塔入口墙段，留出实际可进入的侧门。
- 提高关闭闸门的上边界，加入配重开关控制的机房出口，避免直接跃过机关要求。
- 活塞改为保持固定高度的分段长度图像，让危险实体的高度与碰撞范围一致；预警覆盖完整伸出距离。
- 角色直接向下冲刺时取消默认水平分量，和向上冲刺规则对应。
- 出口改为在顶部平台落地后结算，避免自动结算阻止玩家探索出口附近遗物。
- 独立从受版本控制的源图集生成角色帧图；使用隔离目录验证不依赖战斗缓存。
- 最佳纪录按难度分别计算；完善载入超时反馈与重开后的说明文字。
