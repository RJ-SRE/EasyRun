# 验证与证据

基线：2026-10-24。测试结果分为运行正确性、画面观感、性能观察和真人可玩性，不能用其中一项替代其它项。

## 1. 可复现命令

```sh
bash scripts/with-env.sh pnpm game:build
bash scripts/with-env.sh pnpm game:test
bash scripts/with-env.sh pnpm game:test:legacy
bash scripts/with-env.sh pnpm game:package
```

`game:test` 使用自己的随机端口服务，退出时清理该进程；保留用户已打开的 4177 试玩服务。每个测试使用独立 Chromium 上下文，不污染实际玩家的 localStorage。测试与拆帧显式选择已安装的完整 Chromium 通道，避免本机不完整的 headless-shell 缓存影响运行。

手动启动服务后可单独运行脚本；`RUNLAB_URL` 可指定另一台本地测试服务。所有通关依靠真实键盘输入，没有直接写坐标、分数或胜负状态。

## 4. 性能解释

上一轮本机 Chromium 录制观察的页面 rAF 中位间隔约 16.7ms、P95 约 33.3ms。它受到录制、自动化和浏览器调度影响，不等于引擎内部更新率、每帧实际呈现结果或目标设备性能承诺。研究目录中的简单克隆探针也不能代表真实关卡峰值。

下一阶段应测实际发布设备、连续 20 分钟稳定性、峰值内存、输入延迟、真实网络首启、资源压缩和缓存。本次没有把这些写成已通过。

## 5. CI 与已知缺口

`.github/workflows/verify.yml` 定义 Linux 上安装、构建、当前回归、打包和产物保存。首次远程运行结果另行记录；工作流文件存在不意味着 CI 已通过。旧原型回归和录像不纳入默认 CI 以控制耗时，必要时单独执行。

仍未完成：真人理解/乐趣验证、移动/手柄输入、Safari 与低端硬件、完整 XBuilder 编辑器往返导入、正式线上部署。当前控制器也没有任意斜坡与墙体通用碰撞保证。

- `pnpm game:lint` 检查本版生成器、地图、宿主及测试；`game:package` 验证四个 XBuilder ZIP 与入口。

运行输出在忽略目录 `prototypes/runlab/test-results/belfry/`，选定证据保存在 `docs/evidence/2026-10-24-belfry/`。录像是实际浏览器录制，不是概念效果视频。录制会影响帧间隔；报告中的 `browserFrameCadence` 是宿主页面 rAF 采样，不能等同于游戏实际 FPS。

一次自动化输入路线的速度不等于初玩时长：机器人知道地图和规则，故不据此推断内容价值或用户粘性。尚未完成全收集路线验收、真人试玩、移动输入、手柄、跨浏览器和 20 分钟耐久测量。

本次统一重建前还验证了现有锁文件安装：原本地依赖缓存不完整，离线安装失败；按锁文件联网补齐，保持依赖版本不变。大包下载触及默认超时，使用本次命令级 300 秒下载超时重试，不修改全局包管理器配置。
