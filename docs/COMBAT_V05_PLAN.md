# 倒悬钟城 v0.5：战斗、声音与角色对白闭环

状态：已确认开发范围，验收结果在开发完成后填写。2026-10-24。

## 体验目标

玩家能用位移组织战斗：挑空、追击、拉拽、破甲、坠击构成不同路线。动作有起手、命中与收势，敌人有明确预兆、攻击和破绽。英语是角色表达，不是教学或答题系统。

## 输入与动作约束

J 轻击，W+J 挑空，S+J 空中坠击，L 蓄力重击，E 钩索，K/Shift 冲刺，Q 断弦。轻击命中后允许接其他动作；重击起手与恢复更慢。伤害仅在动作有效帧判断，所有重置清空连段/蓄力/缓冲/临时敌人状态。

敌人的位移冲击采用偏移与速度，常态回到巡逻区。Boss 与闸门守卫不能被永久拖离关卡。不同敌人使用固定循环交替招式，便于学习；模仿者读取最近的玩家动作。新敌人使用独立外观。

## 对白与音频规则

> 声音验收更新：用户已否定系统合成样音的质感。本节原有样音计划仅作已实现基线；新目标见 [暗夜刺客声音重设计](AUDIO_DIRECTION.md)。文件可播放与解码成功不足以满足新的表演验收；新语音包尚未制作。 敌人进一步采用幽甜诱捕、虫性低语、哀鸣与窃声四种自然表演方向，拒绝机器人式声线；新增内容仍为待制作设计。

主角：冷幽默、敏锐、有同理心；敌人：仍执着于旧职责。探索长句只在附近无威胁、主角低速、非返程时出现。战斗短句与死亡不嘲讽玩家。标准对白间隔约 12 秒，安静/健谈可调；同句至少 90 秒。剧情一次性句、回应句都经过同一调度器。危险音效优先，播放对白时轻压音乐。

本版使用本地系统合成的英语样音并保留可替换的文本清单；不是专业配音，也不调用在线 LLM。浏览器读取已生成音频，无运行时凭证。提供音频生成脚本与来源记录。正式商业发行前需换成已确认发行授权的配音资产。

## 开发顺序与完成标准

1. 记录需求；制作攻击与敌人素材、对白清单。
2. 建立攻击状态机、输入缓冲、伤害窗口、敌人偏移和招式。
3. 完成声音总线、对白调度、字幕和设置。
4. 构建并运行针对新机制的键盘测试、音频/暂停/重置测试；回归两种难度完整路线及旧关卡。
5. 更新 PRD、技术说明、素材来源、变更记录；保存截图和测试证据，打包 XBuilder；分阶段本地 Git 提交。

本轮不自动推送远程。完整指本版上述范围在现有单关卡内闭环；不扩展新章节、联网 AI 或付费系统。
