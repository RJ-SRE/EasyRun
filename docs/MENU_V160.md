# 静水圣庭动态菜单 · v0.16.0

> 历史实现，现已由 [v0.16.1 原画微动](MENU_V161.md) 替代。保留本文作为过程记录。

2026-10-27，本地版本，未推送远程。用户选定 B「静水圣庭」后，完成生产素材、共享菜单动画、网页控件和原生 `.xbp` 控件的接入。

## 画面与交互

- 左上小号「裂隙」，左下小比例主角；冷色巨型拱门、悬城与水面留出主要画面空间。
- 右侧主操作：进入钟城、旅人 / 无畏、铭文开关、随行词册、远征设置、排练场、指南和音乐入口。
- 详细词汇范围、作答节奏、拼写提示与音量折叠进设置面板。网页额外保留原有选词策略、词汇难度、跨次记录和续行功能；不冒充原生版已支持这些能力。
- 词册仍可从标题预览、筛选、搜索。查看设置、指南或词册时不再推进主角的叙事动作，独立的轻微风动仍可继续。
- 原生设置含背景音乐 / 动作音效独立滑条和减少动态开关；网页设置内也提供声音入口。默认保持音乐 75%、动作 85%。菜单曲目仍为剪去前五秒的 Red Rock Riviera。

## 动作与节奏

主角十二个源姿态按落脚点注册；主待机有十六帧局部披风风动。运动只发生在角色与局部环境，建筑和镜头不做呼吸缩放。

1. 开场在水边蹲伏，披风受风轻动。
2. 收起细钩线，检查钩头，再放下；在提线时产生两圈错开的椭圆水纹。
3. 下一段抬头望向高处；再下一段低头检查护腕。三个事件轮换，周期为 16 / 18 / 20 秒，动作之间有长停顿。
4. 开始按钮悬停时主角做短暂备行姿态。点击开始或 Enter 立即接收指令，约 0.82 秒起身 / 迈步并渐暗，进入游戏后 0.3 秒淡入；再按 Enter 可跳过。
5. 减少动态时固定主角与环境，不运行水纹，直接进入游戏。网页尊重系统偏好并保存选择，原生仅保留本次运行设置。

水面有衰减倒影和轻薄雾层。角色由分层姿态与短交叉过渡实现，属于二维菜单演出，并非骨骼布料模拟。没有新增角色语音、钟鼓音或额外环境循环音。

新增 10 个固定菜单精灵，无运行时菜单克隆：背景、双层雾、双水纹、钩线、主角、旧姿态过渡、倒影和遮幕。背景静态纹理只加载一次；风动 / 倒影在构建时烘焙，运行时切小图。菜单精灵使用属性缓存，固定位置、造型及可见性没有变化时不重复写入。离开菜单隐藏演出层，后续只保留短暂入场遮幕更新。

## 本机性能结果

相同部署运行时、相同 960×600 浏览器窗口、相同 6.5 秒采样方法，与桌面保留的 v0.15.9 包顺序对照：

| 指标 | v0.15.9 | v0.16.0 |
| --- | ---: | ---: |
| 浏览器帧间隔 P95 | 16.67 ms | 16.67 ms |
| 大于 34 ms 的浏览器帧 | 0 | 0 |
| 引擎平均帧间隔 | 16.67 ms | 16.64 ms |
| 主线程任务时间 / 秒 | 374.4 ms | 389.4 ms |
| 缺失世界精灵槽 | 0 | 0 |

新菜单主线程成本在这一短采样中增加约 4%，没有观察到浏览器帧率下降。这是单次本机短测，不能据此推定所有机器的性能。另一个 42 秒完整动作循环测试含**每帧诊断日志**，该重型诊断下引擎间隔 P95 为 26.13 ms、P99 为 31.28 ms，共 2 帧超过 34 ms；它用于核查动作覆盖、镜头与克隆稳定性，不与轻量基准混用。
