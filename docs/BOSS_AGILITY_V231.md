# Boss 灵活化与重影修复 · 本地更新

2026-11-02。网页版与 XBuilder 导入包共用这一版战斗模拟与角色图集。保持原有钟城背景、三种结构造型、回血规则和单词判题，重点修复后两形态重影，并让移动和招式衔接更紧凑。本文与证据记录本地开发验收；源码同步不替换在线作品，证据中的推送状态保留测试时的事实。

## 重影原因与修复

有两个独立问题：

1. `Enemy.spx` 切换姿势时生成旧身体的混合副本；快速移动又生成固定位置残像。前一种副本继续跟随当前 Boss 坐标，频繁切姿势、形态变化及慢动作会让多具身体交叠。修改前，在隔离测试中，后两形态累计生成 28 个副本，采样峰值同时 3 个。Boss 现在保持单一本体、零透明度效果，不再生成身体副本；`EnemyBlend` 同时拒绝 Boss 副本作为防线。普通敌人仍保留既有过渡，副本显示前先设置位置与透明度。
2. 原图集按固定 4×3 网格直接切割。长刀、链刃、披风和脚部跨越格线，导致当前角色肢体被截断，相邻角色的碎片又进入当前帧。构建器现在先在完整图集上按透明度识别八连通轮廓，再分配至 12 个姿势，保留贴近身体的破布小片，按原脚底锚点注册。三张源图保持原样；36 个派生姿势在构建时重新生成。

修复后测试中，后两形态切招、冲刺的身体副本生成数和并存数均为 0。这个结果描述测试场景，不等于对所有设备帧率的保证。

派生贴图统一扩展为 768×512，脚底锚点同步改为 (384, 490)，仅增加横向透明留白，保持原像素比例。构建阶段校验完整轮廓必须落在纹理边界内；最终 36 帧边缘像素检查均无裁切。这样恢复长刀与链刃的同时，不会因换姿势导致身体位置跳动。

## 体型与步法

| 形态 | 旧显示缩放 | 新显示缩放 | 调整 |
| --- | --- | --- | --- |
| 守铠 | 0.57 | 0.44 | 缩小约 23%，保持有重量的短促推进 |
| 断锋 | 0.57 | 0.40 | 缩小约 30%，低重心退步、掠身回锋、腾跃挑斩 |
| 缚心 | 0.57 | 0.42 | 缩小约 26%，较长肢体与链刃，连续压进与折跃 |

接近速度按阶段为 170 / 225 / 280 世界单位每秒，加速响应提高；观察间隔由 0.65 / 0.45 秒调整为 0.32 / 0.20 秒。朝向增加近距离死区，避免贴身时反复左右闪转。

后两形态在近身观察阶段可以作 105 单位、0.22 秒的小弧线退步，位移受平台边界限制，落地后留 0.28 秒收势。退步不带伤害，冷却为 2.25 / 2.0 秒，不能连续无间隔闪避。跨平台换位采用 0.50 秒固定弧线，不在空中追踪玩家。

Boss 缩小后，箭矢对 Boss 的碰撞半径从 65 收紧到 48，主角近战对 Boss 的额外范围从 40 收紧到 28；仍使用既有近似碰撞形状，并非逐像素碰撞。局部刀刃范围同步缩短，避免视觉变小但伤害范围仍很大的情况。

困难模式仍只按原规则缩短前摇（×0.88）和收势（×0.90），没有额外提高伤害。初次攻击最后 0.28 秒锁向，后续连段不在执行途中追踪。掠身回锋只在第一段落点重新观察一次，然后给出完整的回身前摇；切段时清理旧危险线。三连最后保留较长收势，让玩家有集中反击的机会。

刀光改为贴近实体刃的短金属尾迹：守铠旧金、断锋暗红边缘、缚心冷色刃光。没有环身光环、背景变色或全屏闪烁，依旧只复用 8 个武器段。

## 保留的规则

- 回流普通 9.5 秒、困难 8.5 秒；答题期间回血继续，主动暂停停止。
- 两次不同的有效进攻技能命中打断；同一次 P 多段只记一次，I、普通 J 不增加打断次数。
- 打断回血后的反击窗口仍为 1.15 秒（困难按原收势倍率），不会随普通攻击提速而被缩短。
- 形态阈值、回血预算、次数上限与不复活规则保留。
- 答错取消技能、原有音乐、回声札记、本地存档与菜单保持现有行为。
