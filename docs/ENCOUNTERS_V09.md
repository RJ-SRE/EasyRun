# 配重、镜猎与补给节奏

2026-10-25，`feat/expedition-boss-v2` 开发记录。以下为当前源码行为；完整远征仍在验收，不把专项通过视为真人趣味性证明。

## 双秤货井

两台可载人的金属吊台反向运动；平台、吊链、顶部轮组与碰撞共享实际位置。第一枚扣件开启 45% 行程，第二枚扣件逐步扩大至全程，避免瞬间搬动玩家。配重有独立运行时钟，启动前保持原位。

普通攻击、近身 F 与合适角度的贯夜均可解扣。永久落点与锚点保留基础通路，吊台提供换高差与遮挡的额外选择。返程保留解锁，检查点续行从安全位置接入。

双方射线统一使用当前有效的平台。敌方飞刃按最早遮挡点截断运动，再检测截断后的真实飞行段是否撞到主角。活动吊台、修复支撑可以挡住飞刃；已坠落或未开启的平台不提供隐形保护。

## 交错猎场

短锋与悬刃在距离、视线允许时建立掩护，以细铜虚线表现，线本身无伤害。接通距离 310、断开距离 350，避免临界位置闪断；实体平台可以隔断视线。

连接时双方轮流出招，起手、执行和身法不相互叠加，上一名至少收势 0.30 秒后另一名才能起手。目标离开地面守卫可达范围时，悬刃接过机会，并依据玩家已经发生的位置向另一侧移动。

玩家拉开距离、隔断视线或击破其中一名后，双卫有 1.05 秒不能发起新攻击的重整空档；已承诺的攻击正常完成。重连不提前取消空档。原有全场最多两名起手、最多一名近身控制者的限制保留。

## 存档与补给

每个新房间仍保存进度。完整补给集中在 M01 / M04 / M07 / M10 / M13 与 Boss 前 M15；普通房间不自动补满生命。HUD 分别提示进度保存和生命恢复。死亡续关仍恢复生命；返回已经经过的房间不反复补血。

目标是让受伤与回血选择在区域内有延续性，不为填词数强迫受伤。回血不计入主线基础容量。

## 容量记录

只读 `@skillImpact` 事件记录尝试号、题号、技能、目标与战斗时间。箭矢出生时保存题号，避免把旧箭命中归到下一题；重斩、回血和大招在实际生效时记录。

路线报告区分请求、不同词、正确词、去重后的有效施放，主线收益排除回血、支线守卫与返程敌人。穿透和五连斩仍只算一次施放。完整路线另记录未被控制器及时观察的短暂题目，不隐去自动输入误答。自动答题、死亡后重复遭遇不证明自然学习效果或真人时长。

## 专项与边界

`test-belfry-encounters.mjs` 九项实机检查已通过：真实两扣、平滑扩展、反向承载、答题冻结、活动掩体挡弹、无效平台不挡弹、双卫交替、实际位移断联、房间存档与区域补给。对应报告中两个补给检查分开记录，双扣/承载组合记录，共九项。

脚本使用响应副本布置初始位置与投射物，其后采用真实按键和生产碰撞/AI。双卫调度观察暂时保护主角，该结果不作为难度或无伤证据。报告位于 `prototypes/runlab/test-results/encounters/report.json`。完整路线、Boss、技能、场景预算、音频与旧存档仍须在最终构建上回归。
