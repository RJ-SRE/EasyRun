# 原生成就入口高亮错位修复

2026-11-02，记录原生包的本地修复与验证。源码同步不替换在线作品，证据里的推送状态为验证时的快照。

## 问题

鼠标移至顶部「铭文成就」后，左上角出现浅金色矩形框；在存在纵向留白的窗口里，会覆盖「裂隙」标题。

旧版成就动作编号为 38–41，但原生按钮矩形表没有这些条目。`NativeHover` 按编号减一推导造型索引，导致动作 38 错用清除缓存按钮的 `hover42` 造型；坐标查询又返回 `(0,0,0,0)`，因此矩形被画在错误位置。已用之前交付的 Boss 灵活化包实际复现。

## 修改

- 补齐成就入口、上一页、下一页、关闭按钮的矩形；入口纵坐标随视口高度变化。
- 点击与高亮共用坐标表；造型按实际动作映射，避免依赖编号连续性。
- 无映射或无有效尺寸时隐藏高亮；先设置造型和位置，再显示，避免初次闪位。
- 成就高亮改为轻微透亮和细底线，排在自身面板与顶部栏之后。
- 关闭面板、移开指针后清理高亮；保留普通菜单、设置和清除缓存按钮的既有行为。

## 验证

使用真实 `.xbp` 和本地缓存的 XBuilder 编译器，通过实际鼠标移动与点击验证：

- 960×600、1120×840、1440×720 三种窗口下，成就高亮与入口坐标一致。
- 成就翻页、返回上一页、关闭可用，关闭和移开鼠标无残留。
- 开始按钮、远征设置、单词选择、清除缓存入口正确映射各自造型。
- 包内无测试探针；ZIP 完整性、脚本 lint、`git diff --check` 通过。
- 与上一版包逐字节比较，战斗模拟、Boss 和角色实现没有变化；本次未重复整套战斗测试。
