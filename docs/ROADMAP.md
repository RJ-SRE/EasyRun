# 产品路线：倒悬钟城

2026-10-25，v0.7。当前交付为纵向钩索动作冒险与可关闭的铭文远征，包含五类忍者、四技能、30 词预览与本机进度。后续优先级见本文末尾。下方 v0.5/v0.6 章节保留阶段路线，实际功能以 [PRD](PRD.md) 为准。

## 当前交付：完整单关

- 开场、两档难度、下潜、两道战斗钟门、两阶段核心战、向上逃离与结局。
- 钩索、甩出、二段跳、蹬墙、冲刺、斩击、弹反、坠星、断弦。
- 角色与敌人原图、实际场景、音效、操作指南、暂停、检查点和本机战绩。
- 可重建源码、键盘测试、运行截图、XBuilder 包和规则文档。

准确验证状态见 [TESTING.md](TESTING.md)。这不是多关长篇成品，也不以自动化路线推断用户留存。

## v0.5 已完成

- 多种攻击、地面/空中连段、挑空、蓄力、击退与相撞。
- 四类敌人的两种模式与预警、可剪绊索、模仿动作。
- 角色语音与对白暂时移出当前版本；保留动作音效、环境音乐及操作提示。
- 排练场与覆盖以上行为的实机键盘测试。

## 下一步：观察真实玩家

邀请 5–8 名此前未接触操作的人，各自独立游玩，再复盘：

1. 是否能在不读长指南的情况下理解“按住 E、松开甩出”？
2. 能否看清目标、受击原因、两道钟门和核心战破锁？
3. 他们主动选择的是战斗、探索、收集，还是直冲结局？
4. 失败后是否主动继续，什么时候感到挫败或停下？
5. 对角色动作、敌人和场景的直觉评价是什么？
6. 是否主动组合两种以上攻击，还是始终只按 J/E？
7. 不借助对白，敌人的外形、动作和攻击预兆是否足够鲜明？

记录观察和原话，区分“没有理解”和“理解后仍不好玩”。先修操作与读图，再增加内容。

## 质量迭代

- 为钩索和斩击制作更一致的动画，精修衣摆和关节过渡。
- 细化敌人的出场、退场与肢体动作，降低静态插画感。
- 给不同深度增加更明显的建筑与色温变化、环境叙事、捷径与支路。
- 增加键位自定义、手柄、震动强度和降低动态效果选项，做跨设备测量。
- 检查全收集路线、最短路线、低帧率与长时间重复游玩。

## 扩展条件

当玩家能够独立理解规则，且愿意主动重试并明确指出想探索的内容，再决定第二张地图、更多敌人、进阶技能、商店页与商业模式。当前不承诺真人测试已经完成，也不实现支付功能。

## 2026-10-25 更新：五类刺客基础版

已交付当前单关的五类刺客、独立动作图集、控制与反制、练习选择器及两档通关验证，见 ASSASSINS_V06_PLAN.md。后续优先通过真人试玩观察前摇识别率、被控挫败感、单场战斗时长和钩索使用率，再决定是否加入链条横扫、弓手跨壁龛换位、精英假动作；暂不叠加新系统。

## v0.7 之后的优先级

铭文六类触发、四技能、忍者敌人和单关存档闭环已集成。下一轮优先做同关卡纯动作/铭文对照试玩，观察连续可操作时间、技能回避、受控时长和单词提示依赖，再调题目密度。15%–25% 专注占比仍是体验目标。

随后进行独立词条审校和更多内容；只有当前动作与学习节奏成立后，再把 passages 房型接入同一物理世界。暂不增加付费、语音、账户或自动生成题目。
