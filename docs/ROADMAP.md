# 产品路线：倒悬钟城

2026-10-24，v0.4。当前方向从水平动能跑酷改为纵向钩索动作冒险，依据用户的新需求与开发授权。旧风机片段继续作为历史对照。

## 当前交付：完整单关

- 开场、两档难度、下潜、两道战斗钟门、两阶段核心战、向上逃离与结局。
- 钩索、甩出、二段跳、蹬墙、冲刺、斩击、弹反、坠星、断弦。
- 角色与敌人原图、实际场景、音效、操作指南、暂停、检查点和本机战绩。
- 可重建源码、键盘测试、运行截图、XBuilder 包和规则文档。

准确验证状态见 [TESTING.md](TESTING.md)。这不是多关长篇成品，也不以自动化路线推断用户留存。

## 下一步：观察真实玩家

邀请 5–8 名此前未接触操作的人，各自独立游玩，再复盘：

1. 是否能在不读长指南的情况下理解“按住 E、松开甩出”？
2. 能否看清目标、受击原因、两道钟门和核心战破锁？
3. 他们主动选择的是战斗、探索、收集，还是直冲结局？
4. 失败后是否主动继续，什么时候感到挫败或停下？
5. 对角色动作、敌人和场景的直觉评价是什么？

记录观察和原话，区分“没有理解”和“理解后仍不好玩”。先修操作与读图，再增加内容。

## 质量迭代

- 为钩索和斩击制作更一致的动画，精修衣摆和关节过渡。
- 细化敌人的出场、退场与肢体动作，降低静态插画感。
- 给不同深度增加更明显的建筑与色温变化、环境叙事、捷径与支路。
- 增加键位自定义、手柄、震动强度和降低动态效果选项，做跨设备测量。
- 检查全收集路线、最短路线、低帧率与长时间重复游玩。

## 扩展条件

当玩家能够独立理解规则，且愿意主动重试并明确指出想探索的内容，再决定第二张地图、更多敌人、进阶技能、商店页与商业模式。当前不承诺真人测试已经完成，也不实现支付功能。
