这是一张分成五区的完整纵向关卡，十五房与长篇支线尚未完成；自动化成功不能说明真人愿意继续玩。

## P0 · 验证理解、连续动作与主动重试

先邀请 5–8 名未玩过的成年玩家，交替体验同关卡的纯动作与铭文模式。第一轮用于发现问题，不能据此估计市场规模、留存率或学习效果。当前尚未完成该轮招募与测试。

| 观察               | 如何记录                                             | 决策用途                     |
| ------------------ | ---------------------------------------------------- | ---------------------------- |
| 钩索是否易懂       | 第一次按住 / 松开的尝试、求助点、失败位置            | 改引导与目标提示             |
| 伤害与控制是否可读 | 受击原因解释、对前摇 / 链钩 / 擒拿的反应             | 改敌人预警和保护规则         |
| 是否回避蓄力技能   | 同一遭遇的技能次数、答题前后的操作连续性             | 调整触发密度与恢复反馈       |
| 提示依赖和错词复遇 | 当前词册导出的有提示 / 错词 / 有效时间               | 改词条与复习策略             |
| 成就是鼓励还是干扰 | 主动试新连招、提示是否遮挡、是否为刷成就重复无趣动作 | 调整条件与通知位置           |
| 是否愿意再来一次   | 自发重试、退出节点、原话                             | 判断应扩内容还是先改核心循环 |

15%–25% 的前台专注占比仍是设计目标，不是已测事实。出现明显卡顿感、读题忘记落点或连续受控时，先查输入 / 表现 / 遭遇组合，不以更多粒子或更多成就代替修正。

## P1 · 内容准确性与质量

- 独立审校当前 82 个词的目标义项、词性、短语境和干扰项；修订后更新内容版本，确认旧存档的迁移 / 回退规则。
- 在当前提交重跑完整路线、全收集、不同失败点和长时间重复游玩；成就轮只做了相关规则与回归，没有新录真人无伤整关。
- 以目标设备测首启加载、峰值效果、连续 20 分钟稳定性和内存；宿主 rAF 数据不能替代引擎 GPU 或输入延迟。
- 精修主角与敌人的关键姿势、衣摆和动作衔接。已有短锋架势 / 飞踢、壁弓蹬墙、缚索低扫，不再把这些列成尚未实现。
- 核对干净环境与 CI 浏览器安装、打包、完整 XBuilder 编辑器往返导入；按实际结果修流程，不预先写通过。

## P2 · 三十词远征的最小关卡切片

[五区十五房策划](planning/thirty-word-expedition/README.md)包含更完整的十五房拓扑、语义机关、词义影响路线及换境复核。五区背景和基础修复已在主游戏实现，但原提案没有因此全部完成。下一次实施先做 R03 / R04 / S02 的 3–5 分钟灰盒，验证“词义改变选择”和动作连续性，再决定逐区扩展。

| 可复用                                                       | 仍需开发与验证                                                                     |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| 五类刺客、四技能、输入隔离、词池种子、独立表现时钟、成就基础 | 独立房间与支路拓扑、语义模板匹配、全局 25 秒 / 90 秒调度、跨房间复核、区域资源组织 |
| 现有源图风格与通道实验的经验                                 | 新房间碰撞与遭遇扩展；不能直接把两个运行时拼接                                     |

用户已取消答对后的免题续招，后续方案也不再以此为基础；全局节奏调度仍待验证，解控按当前规则独立出题。原来的三天两夜只能作为小切片的资源约束，不能承诺五区完整版。

## 扩展与排除

只有玩家能独立理解规则、愿意重试并说明想探索什么后，再排第二地图、更长叙事、键位自定义或手柄适配。触屏、排行榜、云存档、每日挑战、付费、账号、在线 AI 出题与角色语音不进入当前开发范围。

[五条 Issue 草稿](issues/2026-10-25-backlog.md)仍未发布；正文是 v0.5 时的草稿，顶部新增状态核对说明哪些已部分改善、哪些仍需验证。用户已选择留在仓库，本轮不为项目热闹而制造缺陷报告、用户数据或远程互动。
