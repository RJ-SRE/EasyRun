# 守心者重新设计 · 结构、动作与反制

2026-11-01，策划稿 R1。依据用户最新反馈，**撤销 v0.21 背景换色、侵蚀层、全身色阶和新增光环**。本文的造型、九招与动画是下一轮制作规格，尚未作为新 Boss 实装。当前恢复包只撤回上述视觉内容，保留 v0.20 战斗与学习规则。

## 1. 这次解决什么

上一版的差异主要来自整体换色、放大以及角色外部的几何装饰。武器、动作与命中效果缺乏联系，漂浮图形也与细致的钟城背景不协调。重做需要同时解决：

1. 去掉颜色和特效后，仍能仅凭黑色剪影辨认三个阶段。
2. 看到起手姿势，就能理解下一击从哪里来、应该往哪里躲。
3. 每次进化都改变交战距离和玩家决策，保留可学习的应对方式。
4. 华丽来自刃口轨迹、重心变化、材质碰撞和准确节奏。

背景保留原钟城原图、原有层次与镜头。菜单、音乐、英语成就和学习边带不随 Boss 重新设计而改版。取消全身红/蓝滤色、环身光环、悬浮剑盘、魔法阵和贴在人物背后的几何“武器”。

## 2. 角色与视觉锚点

守心者是一具以钟心驱动的非人守卫。它不断解除保护自己的结构以继续执行守护指令；越战斗越暴露内部，动作逐渐失去正常守卫的克制。

三个阶段保留四个识别点：同一只尖喙白瓷面具、同一处胸口钟心、同一条破损灰布下摆、同一件武器的结构来源。不要把进化画成三名无关敌人。

材质约束：

- 铁、旧铜、白瓷和灰布保留材质各自的固有色及明暗，不能整具角色映成一种颜色。
- 锈蚀、露出的连接杆、磨亮的刃口、瓷片缺口体现阶段差异。
- 发光仅发生在眼缝、胸口孔隙及短暂刃口接触处，目标占角色可见面积不超过约 5%。
- 面具下无真人面孔。第三形态的“骨感”来自瓷片、金属肋架和细长关节，不加入血肉肢解。
- 背景和人物分层调对比；不改变背景色来“抬高”角色。

## 3. 三个形态

| 项目 | I · 守铠 | II · 断锋 | III · 缚心 |
|---|---|---|---|
| 剪影 | 直立、宽肩、重甲闭合，竖持长柄刃 | 一侧肩甲脱落、胸甲开裂、身体前倾，双刃错位 | 连接肢伸展、重心降低，一手支地，另一臂牵着链刃 |
| 材质 | 大面积旧铜黑铁，小面积完整白瓷 | 新断口露出暗色金属筋，布料缩短撕裂 | 胸前外壳残缺，内部连杆、瓷片与残布裸露 |
| 武器 | 双手长柄双刃，长距离、重承诺 | 原长柄武器在接头处分离为主斩刃与副手短刃 | 断刃由前臂机械链连接，另一前臂展开为固定钩爪 |
| 待机 | 双脚承重、刃尖点地，胸甲小幅起伏 | 身体斜向压低、副手贴胸，偶尔修正失衡 | 头部略偏、一手间歇撑地，链条先松后绷 |
| 移动 | 踏步、转髋，武器有惯性 | 交叉步、侧切、短促掠进 | 支地折跃、长肢回收，不瞬移、不无预兆贴脸 |
| 压迫方式 | 逼玩家处理距离和不同高度的刃线 | 逼玩家识别第二击，不能第一击后立即贪刀 | 逼玩家判断链刃往返、身体落点与连段终点 |
| 可反击点 | 重击落空后收刀较慢 | 双刃连段结束，副手尚未重新护住胸口 | 链刃卡地或完整三决结束，钟心短暂无遮蔽 |

不按阶段继续放大体积和血量。第三阶段通过伸展后占用的空间更大、动作更不安定来体现危险，保持脚底、身体与武器的实际判定关系。

## 4. 两次进化的动作

### 守铠 → 断锋，拟定 1.6 秒

1. 0–0.35 秒：长柄刃撑地，原先平稳的站姿第一次明显失衡。
2. 0.35–0.85 秒：破损肩甲从连接处掉落；掉落件只播放一次，不形成新障碍和伤害。
3. 0.85–1.25 秒：手臂用力扭开武器接头，长柄拆成主副刃，胸前护板被内部连杆顶开。
4. 1.25–1.6 秒：压低身体，副刃护胸，进入新的待机姿态。

### 断锋 → 缚心，拟定 1.9 秒

1. 0–0.4 秒：主刃插地，另一只手压住胸口，核心短暂变亮。
2. 0.4–1.0 秒：裂开的护胸向两侧折开，连接肢伸长，肩背失去原来的对称性。
3. 1.0–1.5 秒：从前臂抽出实物链条，将断刃带回；钩爪张开并撑地。
4. 1.5–1.9 秒：身体拉低，头部转向玩家，以新的支地站姿结束。

进化清除旧攻击，不改变玩家站位，不重播背景音乐，不额外震屏，也不改变背景亮度或色相。进化期间短暂无伤害交换，血条保留阶段刻度；结束至少 0.5 秒观察后才开始下次预备动作。减弱动态时用几个稳定关键姿态完成，不能省掉阶段信息。

## 5. 九招与玩家应对

以下秒数为**普通难度首轮调参值**；从实际起手开始计时，不包含走位。伤害、延迟和范围最终需由完整动作帧与碰撞录制验收。普通攻击均 1 格伤害；困难模式只考虑让第三形态终式最后一击为 2 格，其余先保持 1 格。

| 形态 / 招式 | 预备动作与时机 | 执行与表现 | 玩家解法 / 反击 |
|---|---|---|---|
| I · 衡刃横断 | 0.85 秒；前脚扎稳，长刃沉向身侧 | 约 170 世界单位低位实体横扫，活跃约 0.16 秒；刃弧薄、落空无火花 | 跳过低刃、退到刃外或绕背；落空后约 0.8 秒收刀 |
| I · 穿阶推进 | 0.95 秒；刃尖平指，后腿蓄力；最后 0.28 秒锁定路线 | 向前约 200 单位推进，活跃约 0.3 秒；躯干、握杆和刃尖连续移动 | 看见锁向后跳开或冲过身侧；约 0.9 秒回收，不追着玩家改方向 |
| I · 断阶劈落 | 1.05 秒；双手过顶，视线和重心朝向明确 | 向身前近距离劈落；只有落刃附近短促碎屑，没有全平台震荡波 | 向侧后移动；专门惩罚无脑跳在头顶，结束约 1.15 秒可反击 |
| II · 折返双割 | 主刃 0.65 秒起手，第一刀后副刃再准备约 0.4 秒 | 第一刀掠过后，身体转髋、另一只手反向切回；两个独立伤害窗口 | 不在第一刀后贪技能；副刃回收后约 0.9 秒反击 |
| II · 俯身掠切 | 0.8 秒；单侧肩部压低，主刃贴身 | 沿已锁路线掠进约 240 单位；沿实体刃口切过，不用整块身体碰触持续扣血 | 越过低位掠切或斜向冲刺；约 0.85 秒回到平衡 |
| II · 挑刃封空 | 0.75 秒；副刃先收至腰侧，主刃由低处上挑 | 身前约 140×180 单位的上挑弧；弧度跟随手臂，约 0.2 秒有效 | 贴地绕背或后撤；约 0.9 秒收势。不能连续重复此招封死跳跃 |
| III · 缚刃回收 | 0.95 秒；链刃垂下，手臂指向落点并锁定 | 刃抛出约 0.2 秒，卡地约 0.5 秒，链收回约 0.3 秒；只有刃本体及绷紧回收段有伤害 | 越过刃路、接近暂时空手的身体，或在卡地窗口用 J 击偏刃头，制造约 0.8 秒失衡 |
| III · 支地折跃 | 0.9 秒；钩爪撑地，后腿和腰部收紧 | 清晰弧线折跃到已观察的侧面落点，活跃约 0.35 秒；落地碎屑范围约 70 单位 | 冲入跃起后的下方空隙，或钩索离开落点；落地约 1.05 秒可追击 |
| III · 葬刃三决 | 首段 1.1 秒；低斩前重心压下 | 实物低扫 → 斜向高割 → 植地收链；段间各保留约 0.35/0.45 秒可辨动作 | 高低变化与冲刺配合，保留位移避开末段；完整结束约 1.25 秒，适合 U/L/P 反击 |

三决不是三条屏幕激光，也不是三次全屏伤害。每一段都必须能指出“哪一只手、哪件武器、哪段路径正在产生伤害”。链条松弛时无伤害，装饰碎布和掉甲也无伤害。

## 6. 选招、连段与公平难度

- 第一形态先建立三个距离层次；第二形态开始接续短连段；第三形态组合已经见过的刃路，再增加实体链刃往返。
- 第一形态通常一招一收势；第二形态最多二段；第三形态最多三段。一次完整连段后必须有明确恢复期。
- 基于实际观察到的距离、高差和最近两次站位选择动作，不读取玩家按键，也不在玩家按下技能时临时改出招。
- 锁向之后保持路径。需要转身的第二刀必须播放新预备动作，不能偷偷追踪到身后。
- 过去三次决策中同招最多出现两次；上挑、俯冲和远程链刃有额外间隔。避免低位/高位攻击随机覆盖所有逃生方向。
- Boss 房间不叠加额外远程小怪和自动落刃。一次最多一个攻击序列，镜头不被攻击特效推动。
- 普通 J 在收势、绕背和链刃卡地时有效；连续硬直不能锁死 Boss 的已承诺动作。正面守势阻挡轻击，重击可破准备，执行阶段不因轻击重置。
- 不把 U/L/P 设成永久免疫的钥匙。玩家可以靠熟练基础动作完成战斗，但站桩连按 J 不会稳定通过。
- 困难先将准备/恢复缩短约 10%–15%，再调整选招；不同时加血、加速、加伤、缩范围。72/90 生命暂沿用当前版本，先验证动作带来的难度。

## 7. 回血与英语机制重新协调

用户要求保留：**作答时 Boss 的回血继续；拼错、选错或超时取消主角技能**。普通攻击、弹幕、位移和碰撞仍冻结，主动暂停仍冻结所有计时。

回血动作不画法阵：Boss 将实体刃插地支撑，另一手压住胸口，内部夹具慢慢合拢；光仅从修复中的胸甲裂缝泄出。第一次有效技能命中震开一只夹具，第二次有效命中令其失衡、修复中断。用局部碎屑、胸甲开合和收势表达，不画环身圆圈。

为了让两道实际单词题具有可完成的操作时间，**下一轮拟将回血总窗口从当前 6.4/5.8 秒改为普通 9.5 秒、困难 8.5 秒**：

| 规则 | 普通 | 困难 |
|---|---:|---:|
| 修复准备期 | 2 秒 | 1.7 秒 |
| 准备后回血间隔 | 0.9 秒 / 1 HP | 0.8 秒 / 1 HP |
| 单次恢复预算 | 最多总生命 10%，向下取整 | 同左 |
| 第一枚打断证据保留 | 6 秒真实活动时间 | 5 秒 |
| 次数 | 每形态最多 2 次，启动即消耗 | 同左 |
| 打断 | 两次独立 U/L/P 施放实际命中 | 同左 |

修复不超过当前形态血量上限，不回退阶段。第一次命中不暂停或延长读条，P 五段只记一次；I、普通 J、钩索和未命中不增加打断。修复冷却 15/12 秒先沿用。

这是给“蓄力—答题—命中—接第二技能—再次答题”留出真实时间；如果一次拼写就耗尽整个修复窗口，玩家很难通过选择与练习改变结果。扩大修复窗口后用有限回血预算控制拖延，不靠无限回血惩罚输入速度。

血条旁保留小型剩余时间和 0/2、1/2 反馈；第一击后提示“夹具已松”，成功后“修复中断”，避免额外大弹窗。题卡位置与大小保持，背景音乐不暂停、不压低。

## 8. 技能特效与音效制作规格

动作示意：[三招的准备—执行—收势关键姿态](../design/boss-rework/2026-11-01/keeper-attack-keyposes-concept.png)。此图用于沟通动作和薄刃尾迹，不是可直接用于游戏的帧图集；判定及时间以下面的规格为准。

每招拆成准备、有效段、命中、结束四层。**落空时只保留武器运动和风切声**，不播放命中火花、重响、停顿或震屏。

| 层次 | 画面 | 音效与时序 |
|---|---|---|
| 准备 | 握法、刃角、躯干压缩、脚底受力；最多一段贴着刃口的微亮边 | 皮革、链条收紧、金属摩擦，提示方向与重量 |
| 有效段 | 跟随实体刃口的细窄弧形残影；亮边前、暗尾后，2–3 张短帧衔接 | 一次有速度变化的风切声，不能用长嗡鸣覆盖整个招式 |
| 击中 | 接触点约 6–10 枚短火星或瓷屑，方向与碰撞法线一致 | 材质碰撞与短低频重击；命中停顿先限制约 25–35ms，不叠加重复停顿 |
| 落地 | 手/脚/刃尖的实际接地点扬起小范围尘土 | 石面擦动和局部撞击，避免恢复钟鼓 |
| 结束 | 武器受惯性拉回、布料迟半拍落下，尾迹约 100–180ms 消散 | 一次轻回刃或链条松落，不重复播放强音 |

视觉约束：

- 不渲染长矩形伤害条、箭头、虚线激光和满屏发光扇形作为正式美术。测试碰撞框只在调试模式可见。
- 伤害轨迹与武器实际扫过的区域一致；特效外缘不能让人误以为更大的区域都会受伤。
- 链刃必须有接头、重量和松弛/绷紧变化；不能只拉一根发光直线冒充链条。
- 主角在接触时仍能被看见；身体不被大面积白闪淹没，UI 与中文释义不受后处理染色。
- 大招效果在镜头内出现一次主峰，其余分段降低亮度。降低动态选项减少残影和碎屑，保留必要刃路。
- 音乐、动作音效独立调节；不新增语音、钟声或全程低频环境轰鸣。

## 9. 场地与纵向玩法

不重画钟城、不加机关、不破坏永久平台。第一阶段主要在主平台建立距离判断；第二阶段会用已有侧台和转身动作压迫；第三阶段在主平台及相邻高度间折跃，落点始终在镜头可预见范围。

钩索作为改变高度、越过低刃和快速接近空手 Boss 的工具。Boss 不频繁跑到屏幕外追迫玩家，也不长期站在平台下隔墙打人。Boss 的追位动作必须尊重现有平台碰撞，不能靠瞬间改坐标解决寻路。

## 10. 状态机与攻击判定契约

`观察 → 选择动作 → 准备 → 锁定 → 有效段 → 回收 → 观察` 是基础链；双割和三决在中间显式进入下一段准备。修复、失衡、进化和死亡为独立分支。

- 每段攻击拥有唯一事件 ID；同段最多伤害一次，下一段才能重新命中，仍尊重主角受击保护。
- 武器和链刃使用连续扫掠判定，依据相邻两帧的真实刃口/链端位置，避免高速穿透。
- 位移引导、碎甲、布料、尘土无伤害；碰撞线段只描述已承诺路径，不在有效段重新瞄准。
- 命中停顿只影响普通战斗时钟；回流使用独立计时。暂停/词册/成就界面的恢复不补算已冻结攻击。
- 进化、重开、死亡、退出房间使旧攻击 ID 失效；已经飞出的旧链刃/投射物不能在新阶段继续命中。
- 英语题的请求序号、独立技能施放编号和攻击段 ID 分开，P 多段不会重复计算学习完成或回血打断。
- 新设计最终替换现有十招序列与危险线表现；不能只修改招式名称，继续播放原来的激光条。

## 11. 美术与动画交付清单

先完成真实动作和注册点，再写伤害范围。不能把一张概念图切成几块，当作完整动画。

| 资产 | 首轮最低要求 |
|---|---|
| 三形态主造型 | 正侧视/四分之三参考、背面材料说明、同尺度黑剪影；脸部、核心和脚底统一 |
| 待机 | 每形态约 4 张，脚底不滑，披风和链条只有从属微动 |
| 移动 | 每形态约 6 张，受力脚、转身和进退注册点明确 |
| 九招 | 每招至少 8 个关键帧：3 准备、3 有效、2 回收；双/三段再按需要补帧 |
| 修复 | 每形态约 8 张，插刃、压胸、夹具闭合、受击开裂可区分 |
| 失衡 | 每形态约 3 张，不能被普通受击自动覆盖 |
| 两次进化 | 每次约 12 张；掉甲与武器拆分连续，造型锚点保持 |
| 死亡 | 约 12 张，机体失力与核心熄灭，无巨大光圈爆炸 |
| 刃弧/碰撞/尘土 | 每类独立小图集，限制显示范围和寿命，不烘进整屏图片 |

约 170 张关键帧是制作预算，非已交付数量；连招补帧可能增加。优先做 I 形态完整一招的纵向切片，在实际游戏缩放下判断质感与流畅，再制作后续形态。全部图集需要清理透明边缘、脚底注册、武器端点和镜像方向。

## 12. 开发次序与验收

1. **本轮视觉撤回**：恢复原背景和原本体贴图，移除新增光环/侵蚀层；保留已有战斗、词题和存档。
2. **首招切片**：I 形态待机、完整横断与落空/命中两种反馈；实测刃路、节奏和缩放质感。
3. **I 形态闭环**：三招、正面守势、距离策略、修复、击杀/重试。
4. **II 形态**：真实拆甲与拆刃过渡、双割、掠切、封空；验证不能靠固定连按绕过所有出招。
5. **III 形态**：长肢支地动作、实体链条、折跃和三决；所有远程伤害与实物对应。
6. **整体回归与调参**：英语开/关、普通/困难、不同词长、连续错误、暂停恢复、窗口变化、低配性能。

验收必须包括：

- 去掉特效与颜色仍能区分三形态；缩至实际角色显示尺寸后能分辨手部、刃口和重心。
- 每招在正常速度下有至少一种不依赖特殊技能的躲法；躲法不要求站在单像素位置。
- 连段末尾有足够反击窗口，主动蓄力与单词机制能接入；没有永远无法出手的追击循环。
- 记录 J 站桩、全程后撤、固定跳跃、只放 P 等策略；成功应来自正确站位和时机，不能由永久硬直或固定安全角落绕过战斗。
- 普通模式的中等长度词题能在修复窗口内完成两次有效技能；长词、错误和超时不额外偷扣生命。
- 特效关闭后碰撞不变；掉甲和链条装饰不产生隐形伤害。单段伤害一次、跨阶段旧攻击失效。
- 比较修改前后的帧时间分布与长帧，不只看平均 FPS；制作目标维持 121 个世界显示克隆和 8 个危险槽，装饰优先使用固定对象与小图集。

## 13. 当前实现边界

当前 `0.21.1-local.1` 是**视觉恢复基线**：原背景、原 Boss 图集，无新增环身装饰、整体色阶或场景侵蚀层。大体型锁定圆盘和 Boss 起手圆形提示也撤下，回流、阶段变换和词题仍正常运行。
