# 单词选择统一修订 · v0.18.1-local.1

日期：2026-11-01。本次仅本地交付，不导入线上工程、不发布、不推送 GitHub。

## 修复原因

四种选择此前被 `nativeCoreBank` 内容开关包住，默认包仍走三项考试分类。现解除菜单与内容来源的耦合：网页与独立 `.xbp` 均只保留“普通、困难、挑战、随机”，默认普通。单词选择不改变战斗难度、提示方式或作答节奏。

## 实际规则与内容边界

- 普通、困难、挑战分别从当前词库的第 1、2、3 个游戏难度池抽取。
- 随机使用三池的去重并集；先考虑新词、待复习、薄弱、熟悉配额，再无放回抽取 30 词。不是先随机一个难度，也不是固定每层 10 词。
- `.xbp` 设置行按普通 → 困难 → 挑战 → 随机 → 普通循环；网页下拉框展示同一组选择。
- 每次切换重新准备 30 个不同 ID。R 保留本局词册。完整词库入口始终可查看全部词条，不能被当前难度误过滤。
- 同一个词在不同模式中共享稳定 ID 与学习历史，不按模式重复存档。

当前仍打包 8,815 条既有词库，沿用已有的人工分组及拼写复杂度分组。这是游戏难度，不是 CEFR、官方考试等级或全新的常用核心词库。没有把考试标签映射成难度，没有将旧库标记成已经审核完成的 Oxford 3000。后续真实核心词库启用时使用其通过审核的 difficulty 字段；现有来源、许可和题目质量边界仍见 [词库说明](WORD_BANK.md)。

## 存档兼容

内容版本与词条 ID 不变，不清空历史。IndexedDB 档案头新增 `selectionVersion:1`，支持 0～3 四个模式索引；读取缺少此标记的旧档案时，考试范围重置为普通，其他设置和所有词条状态恢复后原子补存标记。未知的未来选择版本拒绝覆盖。

网页版旧 scope/tier 设置移除，未开始的旧词册按普通重建，学习记录保留。已经开始或归档的旧词册作为随机池中的锁定词册保留；续行恢复其实际模式。新词册记录自己的 wordMode，避免切换后给旧词册贴上新难度名称。
