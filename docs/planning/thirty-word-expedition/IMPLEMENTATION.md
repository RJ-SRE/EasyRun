## Boss：守心者三形态

1. **守阵重甲**：保留首次两侧吊环破锁；锁解除后不再重复封锁。正面轻击可被起手护架挡住，背面和收势可反击。横扫、长距离突进与落点冲击不同解法。
2. **解甲追猎**：外甲脱落，跨台换位、斜向掠袭、分叉刃投掷。判断玩家已经发生的位置/移动，提前锁定目标，不读取按键或在出手后无预告追踪。
3. **裂心悬刃**：核心外露，空中刃阵和两段追猎；第二段有独立起手。招式结束给更长破绽，玩家可用熟练反制结束战斗，不以无限召唤/回血拖延。

所有伤害仅由战斗时钟推进；答题、暂停、死亡、重开与形态切换清理旧攻击。攻击轨迹和落点预告由同一数据驱动。难度主要来自招式组合、站位和节奏，不能只增加血量；纯动作基础攻击必须存在可行击杀路径。
