2026-10-25。用户授权完整设计与开发。状态：开发中，未验收。

## 范围

- 删除配重、货笼、护灯、运输匣、档案底座、回路按钮、机关支线及 Boss 外置钟锁；不再依赖 F/V 操作通关。
- 五区十五段建筑路线，常规遭遇可绕行；三场精英战承担进度检查，Boss 后高速上返。
- 八类敌人：悬刃、短锋、壁弓、缚索、封脉、裂甲卫、棘背猎兽、缝魂师。新增三类独立六姿态透明图集。
- 受伤与打断分离，重甲正面护架、重斩破架、轻敌连击、机动撤步；不能用永久霸体替代 AI。
- 三场精英：裂甲执刑者、双生猎手、折翼审判者。最终守心者三形态七招直接交战。
- U/L/I/Q 每次有效施放都答题，失败取消、无冷却、无免题续招；J/钩索/冲刺维持动作连续性。背景音乐不衰减，无对白、钟鼓。
- 新旧冒险存档迁移不清除 30 词池与答题结果；移除过时机关目标和成就入口，新增真实战斗成就。

## 完成标准

1. 默认构建无机关实体、无机关提示、无外置锁定依赖；完整下潜 / Boss / 上返可完成。
2. 八类敌人均有可见起手、实际伤害、反制窗口和对应图集；三类新敌人可在公开排练场单练。
3. 站桩 J 面对护架失败；绕背、破架成功；轻敌仍能被打断。连续 Q 不能无条件覆盖所有敌人。
4. 支援连接受到距离、视线和死亡限制；猎兽扑击承诺路径且仅命中一次；精英行为不只增加血量。
5. 答题与暂停冻结新 AI，恢复不补伤害；重开/重试清理攻击、连接与临时护架。
6. 存档、音乐、铭文、成就、场景对象预算和整局流程实测；自动测试不冒充真人趣味性与学习效果证明。
