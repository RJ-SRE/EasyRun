# 裂隙：回路遗迹 · 通道关卡 PRD

日期：2026-10-25。范围：独立完成横向、下降、上升及墙体机关关卡，不修改另一对话正在重构的敌人系统。

## 目标与地图

折叠回廊 → 换壁深井 → 配重机房 → 摆渡长廊 → 逆风竖塔。世界连续、镜头双轴跟随、五个检查点、八个可选遗物。完成五类机关与移动挑战后抵达高处出口。没有敌人、战斗门槛或击杀资源依赖。

## 验收需求

- 回廊：铜环需实际钩近并拉住，临时桥展开；期限到达前通过，入口检查点支持重试。
- 深井：粗糙墙面支持蹬墙与缓降，三组活塞有预警；操作左右泄压阀才能通过井底侧门。
- 配重：墙环启动两台反向升降台，角色会被平台携带；高处检修台提供探索分支。
- 摆渡：两个沿轨道移动的钩点，跨越宽断口；下方维修梯可以恢复路线。
- 风塔：开启风阀后，周期气流推动角色上升；两侧停靠点、永久锚点和出口组成可读路径。
- 旅人/试炼只改变机关节奏与临时桥时间，不改变移动物理。
- 支持移动、二段跳、蹬墙、方向辅助钩索、释放助推、冲刺、下穿平台；钩索不能穿透关闭的门或实体墙。
- 死亡、暂停、重开、检查点继续、音效静音和本机最佳成绩闭环；浏览器隐藏自动暂停。
- 分区名称、机关状态、方向路标、危险预兆、小地图和操作指南能够帮助玩家理解路线。
- 使用真实键盘输入验证完整路线，不直接写入游戏内部状态。

## 并行开发边界

新增 `passages-level.mjs`、`spx/passages/`、`public/passages.*` 和独立构建/测试/打包脚本；不改写 `spx/belfry/`、敌人资产、默认首页或已暂存文件。

所有关卡实体来自统一的数据文件。后续可将房间几何接入战斗工程；本次交付的试玩入口为 `/passages.html`，属于同一项目的独立关卡模块，不声称已自动合并敌人重构。

## 关卡原则

新机制先单独展示再组合；主线有稳定落点，技巧路线奖励速度与遗物；危险前至少有可读的预兆。失败恢复到当前房间入口，保留已到达分区和已收集遗物；R 完全重置。机关恢复必须可解，避免拉环、门和升降台形成软锁。
