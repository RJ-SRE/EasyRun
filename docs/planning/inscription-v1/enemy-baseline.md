# v0.6 五类刺客：范围、流程与验收

日期：2026-10-25。用户确认前述五类刺客方案后授权完整开发。本文件与当前 PRD 配套；之前的 v0.5 设计作为历史资料保留。

## 本次交付

1. 用悬刃、短锋、壁弓、缚索、封脉替换旧机械敌人；守心者使用短锋流派精英形象，保留两轮钟锁流程。
2. 使用独立透明动作图集，统一比例与脚底注册；观察、脚步、起手、有效帧、收势、受击分别驱动外观。
3. 保留主角现有攻击与钩索，敌人攻击/受击与位移系统互通。角色语音与对白保持关闭。
4. 调整三个近战平台和门守站位；两档难度的下潜、Boss、返程、检查点、结算完整可通行。
5. 公开排练场提供五种单练与组合遭遇；使用真实输入验证，不注入引擎状态。

## 已实现的战斗契约

| 类型 | 招式 | 玩家反制 | 关键限制 |
| --- | --- | --- | --- |
| 悬刃 | 单刀、错时双刀 | 移位、弹反、钩近、挑空 | 起手末段锁向，投掷后有恢复 |
| 短锋 | 斜切、肘击、低扫 | 脱离接招范围、跳扫腿、打断、重击 | 开招有距离条件，三段分开有效窗口 |
| 壁弓 | 普通箭、重箭 | 搭箭时接近、最后锁向后躲避、J 弹反 | 射后回撤到可见壁龛，无瞬移 |
| 缚索 | 钩刃飞行、命中牵引、收链 | J 斩链、E 抓锚点、近身 | 最多 1.25 秒，无硬锁输入，超距/死亡自动解除 |
| 封脉 | 近身擒腕锁肩 | 命中前跳开或打断 | 仅地面，命中后不可挣脱 0.7 秒；释放后 0.4 秒保护、2 秒擒拿免疫 |

控制、受伤、招式与动画使用同一游戏时钟。暂停不消耗控制时长；重开和续关清理控制、蓄力与按键缓冲。封脉控制期间正常输入不排队触发，释放后新输入立即可用。

攻击调度最多两个同时起手/执行名额，其中最多一个近战或控制者。镜头外不能新起手；控制中不新起手且投射物不能扣血。空档通过招式结构给出，不靠无限追踪或直接读取按键反制。

## 验证流程

- 构建：素材导入 → 图集裁帧 → 拼接 spx 主场景 → 浏览器加载/编译。
- 主角回归：连招、长按、挑空、蓄力/暂停、击退碰撞、取消、资源与音效。
- 刺客专项：逐类单练，再组合，检查真实事件与只读遥测；保存擒拿、连招、弓箭和组合截图。
- 生命周期：难度、暂停、指南、钟门、受伤死亡、检查点、重开、导出与布局。
- 完整流程：旅人/无畏分别从入口至结局；旅人额外等待黑潮失败并从返程检查点继续。
- 验证结果与原始报告见 [TESTING.md](../../TESTING.md)。

## 本版的明确边界

当前是五类基础刺客完整玩法切片。缚索横置封路/大范围横扫、壁弓跨壁龛换位与短刀副武器、短锋精英假动作不在本版实现。Boss 复用短锋图集，不是第六套独立角色。生成图集为关键姿势动画加过渡，不是骨骼动画；没有宣称达到电影或商业大作的动作制作质量。

技术测试能证明规则执行和路线通行，手感、可读性和长期趣味仍需真人试玩后调整。无英语学习、付费、联机或新对白功能。
