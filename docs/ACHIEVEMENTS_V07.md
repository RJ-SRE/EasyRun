# 钟城铭录 · v0.7 成就设计与实现

日期：2026-10-25。用户要求加入成就元素；沿用当前倒悬钟城的动作、敌人和铭文规则，成就只记录玩家已经完成的行为。主入口为顶部「成就 N/16」，解锁后可将对应称号佩戴在生命栏上方。

## 体验目标

让第一次成功、组合技巧与困难挑战都有记忆点。成就条件提供新的尝试方向，但不增加出题频率，不要求刷空挥、故意挨打或停下战斗领资源。称号只是身份表达，不改变生命、伤害、掉落或冷却；纯动作玩家仍可获得行旅及大部分技艺成就。

「钟城铭录」是暗铜色的随身册页：未完成为蚀刻轮廓，完成为暖铜印记；每个印记有条件、已记录的最高进度、获得日期与一句世界观短句。使用原创线条徽记，没有卡通奖杯、满屏礼花或人物语音。

## 节奏与交互

- 解锁显示一枚 214px 的侧边小铜牌，约 2.7 秒后退场；不抢键盘、镜头或鼠标，不暂停游戏。多个解锁按队列轮流出现，每项只入队一次。
- 题中、暂停、操作指南、声音设置、词册、成就册或后台时隐藏铜牌并停止其展示计时。回到正常动作或通关页后继续；答题界面优先。
- 成就册主动打开时暂停战斗；关闭时仅恢复由它暂停的游戏。原本已经暂停的游戏仍保持暂停；标题页打开成就册不会开局。
- Esc 关闭，Tab 在原生对话框内移动，Enter / 空格操作聚焦按钮；动作键不会泄露到游戏。进入、离开册页会释放并隔离此前按住的动作键。
- 桌面册页上限 680px，左右分别为印记清单和详情；短屏缩小清单滚动区，窄屏改成单列印记。当前游戏仍面向桌面键盘，窄屏检查不等于完成触屏操作适配。

## 数据与实现边界

成就使用独立的 `easyrun-belfry-achievements-v1` 本机存储，包含版本、各项最好进度、解锁时间、不同词 ID 和佩戴称号。提供 JSON 导出；没有导入、账号同步或联网请求。清理浏览器站点数据会清除记录。旧战绩和旧词册不补发成就，以免把无来源的历史数据当成本轮完成。

引擎在有意义的实际动作上发送带序号、尝试编号、模式、血量等字段的 `@deed` 快照，沿用原 `@event` 的音效与表现。新增安静落地信号，仅用于结束空中连续换钩；不修改运动、敌人或伤害数值。成就判定不依赖可能滞后约 70 毫秒的 HUD 状态。

词汇成就仅接收通过当前行动身份核对、且词册已经成功结算的 `onSettle` 回调。重试和续档明确重置临时连招并取消无伤完整冒险资格；重复事件、旧尝试和重复结算不重复发奖。

解锁和最好进度发生变化时才写本机存储；不新增逐帧循环，通知使用原状态更新，队列最多 16 项。记录损坏时显示新记录提示，存储不可用时允许继续玩并导出当次记录，成就模块加载失败也不阻止游戏启动。没有把浏览器本地记录包装成防作弊排行榜。

网页成就册与本机存储不包含在单独 `.xbp` 中，需使用配套网页版本。五区域和语义机关仍属于后续策划，本次没有以新增成就之名宣称新关卡已经可玩。

## 验收

复现命令（先启动当前构建）：

```sh
bash scripts/with-env.sh node prototypes/runlab/build-belfry.mjs
bash scripts/with-env.sh node --test prototypes/runlab/test-belfry-achievements-core.mjs
RUNLAB_URL=http://127.0.0.1:4184/ bash scripts/with-env.sh node prototypes/runlab/test-belfry-achievements.mjs
```

规则测试覆盖全部 16 项的条件类别、去重、练习排除、重试 / 续档、空中不同目标、词汇唯一性及损坏恢复；浏览器测试通过真实首平台按键解锁落笔成锋、刀锋余响、借风起身，验证成就册、称号、导出、刷新、提示避让和故障回退。罕见的完整无伤通关条件由事件规则测试覆盖，本轮未另做真人无伤整关挑战。
