# 纯本地学习档案验证版

当前版本：0.21.2-local.1（词册外遮罩移除；学习存储结构不变）。成就与学习边带见 [v0.19.0 说明](LEARNING_RAILS_V190.md)。四种选词模式及兼容修订见 [v0.18.1 说明](WORD_SELECTION_V181.md)。此前 0.18.0 本地存储验证始于 2026-10-31，完成整理于 2026-11-01。依据用户最新选择，学习档案改为浏览器本机 IndexedDB，默认不连接后端或七牛，不要求配置 HTTPS 后端。未提交或推送远程仓库。

## 当前已经接入游戏的内容

- `.xbp` 内置 IndexedDB 适配器 `NativeLocal.spx`，不是仅有最小能力探针。
- 按固定游戏标识、结构版本及规范化运行器用户名隔离档案；空名称使用独立本机游客档案，不并入后来登录的名称。
- 保存拼写/辨义独立次数、正确/错误/超时、辅助正确、薄弱度、长期答对/通关标记、复习时间和累计通关次数。
- 保存战斗难度、单词选择、作答节奏、提示、铭文开关、音乐/音效音量和音乐静音设置。
- 每次新外部运行恢复学习历史，在标题准备新的 30 词；游戏内 R 仍保留本局词组。不是从关闭时那一帧的战斗位置接续。
- 标题、暂停和结算显示本机读取、待保存、保存中、已保存或失败状态；只有事务完成才标为已保存。

存储随浏览器网站来源保存，不在 `.xbp` 文件中。把同一个项目包发给别人不会携带你的进度；本机预览地址与 XBuilder 网站也不共享数据库。

## 数据与写入机制

数据库：`easyrun.rupture.learning.v1`，版本 1。

| 对象库 | 保存内容 |
|---|---|
| `profiles` | 档案头：版本、词库版本、修订号、通关次数、设置与保存时间 |
| `words` | 按“档案键＋稳定词条 ID”保存已接触词的能力状态；`byProfile` 索引用于恢复 |

档案键是游戏命名空间、模式与规范化用户名组成的 JSON 数组。名称采用 trim、NFC、转小写。访客和字面名称为 guest 的登录用户使用不同键。名称只是本机记录的选择条件，不是安全认证或加密边界。

答题内存更新保持 O(1)，只将变化的词加入去重脏列表；输入每个字母不写库。每个异步事务最多写 50 个变化词及一个档案头，避免每题重建整个词库的 JSON。写入时又产生的变化根据词修订号保留，事务成功不会清掉较新的脏数据。

恢复时按索引读取当前档案，在标题阶段每帧最多应用 16 个词，防止把全部解码放进一个游戏帧。历史跨词册保存，不只保留最近 30 词。

复习截止时间以绝对时间写入，读回后换算为当前运行器的计时基准，因此关闭游戏经过的时间也会影响待复习状态。

## 多窗口和错误处理

写入事务先读取档案修订号，与当前窗口读到的修订号比较。已有其他窗口更新时中止事务，保留旧窗口内存并显示冲突，不自动覆盖。需要重新运行以恢复最新档案，或按 G 进入临时游玩。两个窗口交替离线合并尚未实现。

- 配额/事务失败：数据库保留上一份完整提交，未保存的变化仍在当前内存。标题 N 可重试，不假装保存成功。
- 存储访问被禁止：使用受控反射调用取得 IndexedDB，捕获可能抛出的 JS 属性异常；失败时可 G 临时游玩。
- 未知结构/词库版本或坏档案：停止写入并阻止以该档案开始，不初始化空档案覆盖原记录；可 G 临时游玩。
- 临时游玩不写入原档案，N 可尝试重新打开原档案；发生版本冲突时不通过 N 强行覆盖。
- 每次操作结束关闭数据库连接并释放临时 `js.Func` 回调。外部停止/重跑的在途事务也已单独验证。

浏览器异常退出前尚未完成的事务可能回滚，本版保证已验证场景中的原子提交，不承诺每次按键后立即永久落盘。实际断电/磁盘损坏不在本轮进程强关测试范围内。

## 实际验证

结果见 [本地验证证据](evidence/2026-10-31-local-only/README.md)：

- XBuilder 缓存运行器完整包 13 项场景通过：两种能力保存、已加载游戏断网保存、提交后 SIGKILL 恢复、事务中止重试、提交前 SIGKILL 原子回滚、多标签修订冲突、名称/游客隔离、100 次作答合并、设置恢复、模拟配额失败、到期时间恢复、未知结构保护及模拟存储访问禁止。
- 500 个已学词的独立恢复测试通过，覆盖多局词册，不遗留回调。
- 同 iframe 外部 stop/init/start 的在途写入恢复测试通过。
- 原有 25 项原生单词战斗回归通过，包括自动判题、错字取消技能、提示渐隐、技能冷却和输入隔离。
- 运行期间观察到的学习后端与七牛接口请求数为 0。

部分异常通过故障注入验证：配额不足/存储禁止不代表真的填满磁盘或修改了用户浏览器设置；强关测试则对独立测试浏览器真实发送 SIGKILL，未关闭用户日常浏览器。

## 使用与构建

桌面导入包：`EasyRun-XBuilder-v0.21.2-ledger-no-backdrop.xbp`。

仓库导入包：`prototypes/runlab/exports/belfry-ledger-no-backdrop.xbp`。

默认构建即本地模式：

```sh
LEARNING_NATIVE_STORAGE_MODE=local bash scripts/with-env.sh python3 prototypes/runlab/package.py --game belfry
```

不需要提供 API 地址或 Kodo 配置。清单明确 `storageMode:local`、`localPersistence:true`、`cloudEnabled:false`、`apiURL:""`。旧云端相关代码和服务保留为历史实现，不由本地模式启动。

测试命令：

```sh
RUNLAB_URL=http://127.0.0.1:4177 XBUILDER_RUNTIME_DIR=.cache/xbuilder-online-20261026 bash scripts/with-env.sh node prototypes/runlab/test-belfry-native-local.mjs
LOCAL_TEST_BULK_ONLY=1 RUNLAB_URL=http://127.0.0.1:4177 XBUILDER_RUNTIME_DIR=.cache/xbuilder-online-20261026 bash scripts/with-env.sh node prototypes/runlab/test-belfry-native-local.mjs
LOCAL_TEST_RERUN_ONLY=1 RUNLAB_URL=http://127.0.0.1:4177 XBUILDER_RUNTIME_DIR=.cache/xbuilder-online-20261026 bash scripts/with-env.sh node prototypes/runlab/test-belfry-native-local.mjs
```

## 目前的限制

1. 清理网站数据、更换浏览器/设备、换站点来源或使用隐私模式，可能无法恢复原记录。没有云端副本，也没有自动跨设备同步。
2. 导出/导入备份尚未实现；不能把“后续可通过备份迁移”当成当前已有功能。
3. 游戏已加载后断网可保存；离线首次打开 XBuilder 网站和下载游戏资源不是本地存档能解决的问题，尚未做完整离线资源缓存。
4. 名称仍采用平台启动时快照，改名后对应另一份本机档案；不能承诺平台在游戏运行中实时推送新名称。
5. 当前固定词库与结构可恢复，跨词库版本迁移尚未实现。检测不兼容时保留旧数据并停止覆盖。
6. 本轮使用缓存的 3.3 运行器和临时浏览器 profile，实际 XBuilder 发布页、其他浏览器与长期性能仍需验证。500 词的冷启动计时包含编译/资源加载，不是帧率基准。
