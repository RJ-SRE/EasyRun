# 守心者三形态 · 开发实现

2026-10-25，`feat/expedition-boss-v2`。这是完整远征开发中的 Boss 重构部分；十五房主线、五支线和变形返程已接入开发分支，仍在完整回归，尚未作为完整版本交付。完整范围与验收账本见 [开发清单](planning/thirty-word-expedition/IMPLEMENTATION.md)。

## 行为与形态

守心者不再执行短锋的通用近战循环。`Keeper.spx` 独立处理观察、起手、锁向、出招、换位、收势和形态转换。第一次两侧吊环仍需拉断；后两次变形不重新上锁。

| 形态 | 外形 | 战术 |
| --- | --- | --- |
| 守阵重甲 | 铜甲、放射冠、长柄刃 | 护阵横扫、地面突刺、落点冲击；早期起手只挡正面轻击，背面与收势可打 |
| 解甲追猎 | 脱去肩甲、双刃与展开的机械肢体 | 二次锁向追斩、散射、跨台俯冲；换位过程可受击 |
| 裂心悬刃 | 开裂胸腔、显露青白核心 | 错时刃阵、俯冲与二段追斩组合；刃阵结束留下较长收势 |

旅人生命 36、无畏 45，按三分之一划分形态；阈值处截断当次溢出伤害，使两次变形均可被看到。变形约 1.15 秒，沿可见曲线回到中心，清除旧刃阵和 Boss 飞刃，不伤害玩家。没有无限回血、召唤杂兵或重复拆锁来延长战斗。

选招依据已发生的距离、高差、上次招式和决策序号，不读取玩家键盘。远距离可突进，高处目标可散射或俯冲。最终 0.30 秒锁定目标；玩家随后移动不会被无预告追踪。二段追斩重新起手 0.60 秒（旅人 0.72 秒），第二段重新观察并独立锁向。

## 招式与反制

| 招式 | 伤害形状与时机 | 可行反制 |
| --- | --- | --- |
| 裁线横扫 | 面前固定刃线，出手后 0.10 秒生效，持续 0.22 秒 | 跳过、退开、绕背；同一斩只伤一次 |
| 贯阶突刺 | 沿锁定路径移动，按本体的逐帧扫掠判定 | 留意末段锁向后跳开/冲刺；落空后反击 |
| 坠炉 | 可见抛物线落向目标，落点横向 200 单位冲击 | 跳过冲击或离开预告位置 |
| 分叉刃 | 三枚真实飞刃，方向锁定；继承普通投射物的斩落和碰撞 | 走间隙、借掩体、J 斩落 |
| 返身双斩 | 第一段路径结束后第二次起手；两段独立锁向 | 留下第二次位移；不在第一段结束时贪刀 |
| 折翼俯冲 | 先跃到一侧高处，再预告斜向路径 | 离开落点；利用支持台接近收势中的守卫 |
| 裂心刃阵 | 三条相距 155 单位的竖直刃线，错开 0.24 秒 | 沿空隙移动；刃阵不是全屏覆盖 |

普通攻击可以击杀；英语正确不代替碰撞、站位或命中。大招仍是答一题后授权五击，无时间冷却；前四击统一各 1 伤、末击 3 伤，取消旧版对 Boss 前四击翻倍的隐藏特殊情况。大招位移限制和动作时长保留；原来整整 1 秒的免伤改为起式 0.35 秒、每次实际挥斩 0.07 秒保护，斩击间隙和末段收势可被惩罚。答题结束的既有 0.4 秒保护不被缩短。后两形态转换后短暂收势即进入招牌身法，不重复额外等待。完整远征的四技能分工仍需结合新房间继续验证。

## 连续性与安全

- 所有伤害、移动和预告年龄只在战斗时钟推进。答题冻结后不会累积后台攻击；回答结束沿原剩余时间继续。
- 两段追斩不能省略第二次预告。形态转换、重新开始、检查点重试与击败 Boss 清理旧危险；飞刃带有专属代次，防止跨阶段残留。
- 镜头在 Boss 区兼顾主角和守卫，并限制在竞技场范围；新增左右两个永久肩台用于高低位换位与反击。
- 美术与判定共用刃线端点、年龄和宽度。移动路径只作提示，不把整条路径当成同时生效的伤害线。
- 恢复原动作输入、音乐正常音量、无人物语音、无新增钟鼓音效。起手/换位/变形复用干燥动作与材质采样。

## 验证边界

`test-belfry-keeper.mjs` 在网络响应副本中布置单招起点和阶段阈值，用真实按键测试伤害/躲避、锁向、三形态、普通攻击击杀、答题冻结与错误取消。它不会修改生产地图或存档，也不代表正常整关通关。自主选招测试的角色保护仅用于观察招式，不能作为战斗难度证据。

完整路线另由 `test-belfry-route.mjs` 验证。测试结果与未完成项应在取得实际报告后更新，不以源码存在宣称完整验收。
