# v0.22.1 · 铭文成就陈列册

将成就页从普通信息卡改为钟城中的刻印陈列。网页与 XBuilder 独立包共同使用 `public/learning-art.js`：尖拱铭牌、旧铜边框、内凹金属印章、九类雕刻图案、罗马序号与底部刻度。没有新增成就条件或改写学习统计。

## 视觉与交互

- 桌面每页四枚竖向铭牌，24 项成就、六页顺序保持。徽记占据主要视觉面积；名称、状态、条件、数量与刻度分层排列。
- 三种材质状态：未练习为暗铁与灰绿；已有进度为旧铜；已铭刻为象牙金、亮边和小确认印。状态同时使用文字、图案和颜色辨识。
- 九类图案重新刻绘：古书、羽笔、洞察之眼、双页铭文、修复碎片、隐字月纹、沙漏、日晷、连绵刻痕。保存文件里的原成就 ID 和规则不变。
- 面板用低透明度深色玻璃与细金属包边，外侧完全透明，保留原建筑、水面和云雾。移除面板后方的菜单／暂停／答题控件干扰；合上恢复原界面。
- 上边带入口改为小型拱顶书印与计数，解锁提示沿用同一材质。下边带单词进度继续保留。
- 网页窄窗口使用两列紧凑横铭牌，卡片区可滚动，标题、翻页和关闭固定可达；原生版在相同比例舞台上完整缩放四枚铭牌。
- 已解锁成就显示完整刻度，即使当前词库统计变化，仍清楚表达历史授予状态；只改变呈现，不向学习记录补写数值。

## 原生实现与成本

装饰由共享 SVG 预渲染到 PNG，游戏中切换静态造型。没有粒子、实时模糊或新增世界精灵。固定 UI 精灵仍为 59，世界克隆仍为 121。

每个成就显示位置只携带自己六页 × 三状态的 18 张造型；四个位置合计 72 张，而不是每个位置重复携带全部 72 张。面板和牌面采用平涂玻璃底、细金属浮雕，减少大面积半透明渐变的纹理体积。页面、状态和数值变更才刷新，继续使用已有精灵属性缓存与字形池。

关键文件：

- `prototypes/runlab/public/learning-art.js`：共享可复现矢量装饰，不使用外部图片或新依赖。
- `public/learning-rails.js`、`public/learning-rails.css`：网页陈列与自适应。
- `belfry-native-study.mjs`：原生造型构建、分位置资产和版式。
- `spx/belfry/NativeStudy.spx`：既有字形图集呈现衬线数字；规则和存档逻辑未修改。
- `build-belfry-native.mjs`：成就册开启时暂时隐藏其他菜单控件，关闭后恢复。

仍保留：战斗暂停／恢复、答题暂停且保留输入、音乐连续播放、方向键翻页、Esc 关闭、设置面板原状态、24 项成就与已有本地存档。不修改 Boss、敌人、技能、词库、音乐或存档版本。
