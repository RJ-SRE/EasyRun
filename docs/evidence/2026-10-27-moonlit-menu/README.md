## 性能方法与限制

[轻量对照](performance-baseline.json)与[新菜单](performance-candidate.json)按相同方法、相同部署运行时、相同 960×600 窗口顺序运行：6.5 秒内浏览器帧间隔 P95 都约 16.67 ms，超过 34 ms 的浏览器帧均为 0；主线程任务耗时由每秒 374.4 ms 变为 389.4 ms，约增加 4%。没有在两次采样间并行运行其他自动化测试。

42 秒完整动作覆盖测试另行记录每帧日志，诊断本身有成本。该诊断下引擎间隔 P95 26.13 ms、P99 31.28 ms，2 帧超过 34 ms；不与轻量采样混用，也不声称所有设备都稳定满帧。原生测试通过已部署的项目模型导出与编译器加载本地实际包，未对用户在线作品执行导入或发布。
