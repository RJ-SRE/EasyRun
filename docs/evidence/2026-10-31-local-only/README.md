测试直接运行打包后的原生方法。临时按键、事务中止与浏览器原型故障注入只存在于测试源码覆盖层，未进入交付包。使用独立临时浏览器目录，测试完成删除；未读取用户实际平台存储、未写入七牛，也未操作线上作品。

强关提交前的测试通过额外只读请求维持真实 IDB 事务未提交，然后向独立 Chrome 主进程发送 SIGKILL。恢复结果为上一份完整数据，不把提交前强关误称为新答案必然保存。提交后强关则验证已完成事务能恢复。

首次完整接入发现 XGo 回调参数名 `this` 遮蔽类接收者，已改为普通参数名；故障测试发现直接获取 `indexedDB` 属性时 JS 异常可能绕过 Go recover，已改为通过 Reflect 的受控函数调用。两项修复后主套件通过。重跑专项最初因测试选择了新词册首词而检查错对象，固定词条 ID 后通过；未因此修改产品存档逻辑。

测试确认提交后回调计数回到 0；这不是浏览器整体内存的长期泄漏证明。配额与权限错误为故障注入，不是实际占满磁盘或对用户浏览器施加限制。500 词恢复使用合成数据，冷启动耗时包括资源和解释器启动。

完整规则、命令与未完成项见 [本地存档说明](../../LOCAL_LEARNING_VALIDATION.md)。未提交或推送远程仓库。
