- 共享美术与页面：3 项，覆盖三状态、独立渐变 ID、24 项原顺序、六页、滚动可达和屏幕边界，[报告](web/report.json)。
- 网页交互：4 项，覆盖菜单打开、设置原状态、战斗暂停恢复、窄窗口，[报告](interaction/report.json)。
- 实际 XBuilder 运行器：28 项，包含原有词机制回归、成就数值向量、六页造型索引、标题／战斗／作答／已暂停状态、音乐继续、输入隔离和小窗口，[报告](native/report.json)。
- 7 项内容／成就单元测试，[结果](unit-tests.txt)；ESLint、`git diff --check` 通过。

最终包仅将页脚字号从测试时的 10 增至原有的 11，其余界面与运行逻辑相同；最终 SHA-256 见 artifact 文件，各测试报告保留其实际包校验值。
