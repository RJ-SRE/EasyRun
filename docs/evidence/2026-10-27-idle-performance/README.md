## 性能对照

同一台 Apple M1 Pro、Chromium 156.0.8078.4、960×600 / DPR=1、无 CPU 限速，部署的 XBuilder 编译器及项目模型。固定词册 25–54、固定场景与操作，逐段预热 1.5 秒、采样约 6.5 秒，两次运行顺序执行。完整环境与原始数据见 [基线](performance-baseline.json) / [新版](performance-release.json)。

| 场景 | 引擎平均帧间隔 ms（旧 → 新） | 页面任务 ms/s（旧 → 新） | 宿主 rAF P95 ms（旧 → 新） |
| --- | ---: | ---: | ---: |
| 标题 | 17.99 → 17.49 | 807.1 → 699.1 | 33.33 → 16.67 |
| 待机 | 20.21 → 19.46 | 918.0 → 895.9 | 33.33 → 33.33 |
| 密集战斗（按住 J） | 36.02 → 34.09 | 981.0 → 984.2 | 66.67 → 66.67 |
| 拼写题 | 18.42 → 17.71 | 783.5 → 734.2 | 33.33 → 33.33 |
| 词册 | 21.77 → 18.64 | 962.2 → 813.3 | 33.34 → 33.33 |

词册平均帧间隔下降约 14.4%，页面任务耗时下降约 15.5%；标题任务耗时下降约 13.4%。密集战斗平均间隔略降，但任务耗时未改善，rAF P95 仍约 66.7ms，新版该段引擎最长间隔约 77.8ms；词册也观测到约 130.8ms 的单次长间隔。**不能声称整体稳定 60 FPS，也不把单次短测中的小幅差异视为保证。**

可以确定的算法工作量减少：每帧场景槽遍历从标题 / 待机的 268、战斗的 380 降至 50；静止 UI 的造型切换与置顶写入降至 0。文字、镜头或状态改变时仍正常刷新。这些计数来自运行内测试计数器，不是从目标帧率反推。

测量包含计数器开销；引擎间隔、页面任务耗时和宿主 rAF 分别代表不同层面，均不是整机 CPU / GPU 占用或呈现帧率。固定输入与位置不保证两个运行的战斗状态逐帧完全相同。没有跨设备、Safari、持续一小时压力或在线账号工程导入验收。
