## 网络现象与清理

最初两轮探测出现网络超时，未记为通过；其中一轮清理时也超时。随后对两个精确测试前缀重新列举和清理，核对为空，见 `initial-probe-cleanup.json`。最终三份通过报告的 `cleanup.verifiedAbsent` 均为 true。

每次测试使用新的 `rupture/learning-tests/<时间和随机数>/users/` 前缀，只写合成学习事件；清理仅处理本次已触及的精确对象，没有清空空间或触及 `rupture/learning/v1/users/` 正式路径。合成会话和密钥不进入截图、报告或 `.xbp`。

请求样本中的 `ms` 是本次网络请求到响应头的时间，用于诊断；不是完整下载时间、正式延迟 SLA 或游戏帧率测试。没有通过增加每次答题请求来获取样本。
