## 本机菜单性能

顺序运行，同一机器、部署运行时、960×600 窗口、6.5 秒采样。基线为桌面保留的 v0.16.0 包。结果仅供本机短测比较，不能代表所有硬件或长时间游玩。

| 指标 | v0.16.0 | v0.16.1 |
| --- | ---: | ---: |
| 浏览器帧间隔 P95 | 16.67 ms | 16.67 ms |
| 超过 34 ms 的浏览器帧 | 0 | 0 |
| 引擎平均帧间隔 | 16.98 ms | 16.69 ms |
| 主线程任务时间 / 秒 | 450.8 ms | 433.4 ms |
| JS 堆快照 | 21.80 MB | 25.87 MB |
| 缺失世界精灵槽 | 0 | 0 |

本次未观察到帧率退步，主线程任务时间短测下降约 3.9%；快照内存有增加，不能声称所有资源成本均下降。两份原始报告分别为 `stillwater-baseline-v160-performance.json`、`stillwater-v161-performance.json`。

另外的 9 秒逐帧诊断检查中，P95 为 18.12 ms、P99 为 25.00 ms，无超过 34 ms 的引擎帧。该测试含每帧日志，用于验证全部局部帧、镜头、姿态和克隆稳定性，不与轻量性能采样混用。

新包约 133.03 MB，上一版约 116.22 MB。增加来自原图局部帧；运行菜单精灵从 10 个减至 3 个。历史图集仍保存在工作区，包内仅包含新菜单精灵。
