## 修复范围

后端原来已经按验证后的 XBuilder `user.id` 派生档案 ID，没有以用户名创建档案。这次修复的是原生客户端和参考客户端：同一账号更新登录凭证时，不再当作账号切换重新准备词册，也不让保存中的回执失效。

- 用户名和昵称可变，不能用作身份主键；缺少稳定 ID 时拒绝建立云身份，不退回用户名匹配。
- 相同 ID 只更新凭证，保留词册、远征、学习状态、未确认队列、冻结批次和请求代次。
- 旧凭证的迟到 401 不覆盖新登录状态，使用新凭证重试同一批次；正常保存回执仍可确认。
- 真正不同的 ID 才走账号隔离与切换流程；其他人使用旧用户名不能获得原档案。
- 不需要用户名迁移脚本，既有 ID 派生规则没有改变。部署时必须保留身份映射密钥与 issuer 配置。
