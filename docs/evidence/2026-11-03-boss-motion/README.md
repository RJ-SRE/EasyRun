## 性能采样结果与范围

本机隔离浏览器，每场景 4 秒。第三形态战斗、菜单、词题、词册的 rAF P95 均约 16.67ms，第三形态样本中未出现超过 34ms 的帧间隔，也没有场景精灵缺失。

静止和普通战斗各记录到一次约 267ms 的 rAF 尖峰，其余采样大多约 16.67ms。因此本次不能宣称全游戏偶发卡顿已彻底解决；短时 Boss 采样也不能替代长时或低配设备测试。`engineFrameMean/Max` 在当前运行器中未获得有效数值（为 0），不作为性能依据。保留 rAF、任务耗时和场景计数的原始数据供后续定位。
