## 定位与改动

诊断使用 CPU profiler，独立于上述最终对照。[三次主要长任务的栈归因](gc-attribution.json)中，约 90% 的采样位于 Go/WASM 的 GC 扫描路径。解释器保留的 Game 方法转发与初始化数据是本次优化目标；这不表示所有小长帧都已逐一归因于 GC。

- 将 Game 上的 103 个原生辅助方法和 104 个世界辅助方法分别移到两个隐藏、无克隆控制器，减少每种精灵产生的重复解释器方法信息。
- 8,815 条词汇与 3,350 个字形映射改为紧凑数据、启动时一次解码。减少解释器初始化对象，目的不是缩小资源包文件。
- 24 段钩索与 8 条首领攻击线空闲时停止逐帧轮询；显示时保持逐帧刷新，退出时隐藏。
- 保留默认 GC 策略、121 个常驻世界克隆、全部美术与音乐。

实现和复现命令见 [性能说明](../../PERFORMANCE_V163.md)。
