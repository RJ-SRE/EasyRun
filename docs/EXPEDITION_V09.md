## 地图与任务

默认构建已改用 `prototypes/runlab/belfry-expedition.mjs`。十五个主线房间贯穿五个地区，地图、机关、敌人位置、检查点、宿主提示、存档迁移与测试使用同一份数据。

| 地区 | 房间与实际任务 |
| --- | --- |
| 风钟门 | 折翼门廊自由移动；双层哨桥接通桥头；悬笼岔井启动运输笼并选择返程停靠 |
| 铸钟炉 | 双秤货井解除两个独立扣件；退火回廊周期热流与泄压；监炉者秤台使用配重诱导链钩反击 |
| 沉水档案 | 侧翻书库排水便道；浮灯渡廊分段引灯；封存大厅读取两份记录并选择原件或目录 |
| 碎镜唱廊 | 倒影长井观察实体路线；交错猎场处理双卫与双锁；折光天桥选择实体桥向 |
| 守心机枢 | 停摆前庭选择留灯或携心；锁心回路从不同高度切断三处目标；三形态守心者与取心返程 |

观察、热流、排水和供能选择房间不要求操作机关才能离开。有任务门的房间依据实际任务状态开门。扣件和回路接受攻击碰撞，也允许接近后按 F；机关不提供击杀数或余烬。

移动平台使用战斗时间，并实际搬运站在上面的角色。护灯由玩家在停靠点放行，受扰返回最近安全停靠点，不重刷敌人、不永久丢失任务物件。热流先预告再判定伤害，有永久安全落点，泄压后关闭。

新增联动反向配重台、逐步扩大的行程、双方一致的活动平台遮挡，以及按距离和视线交替掩护的镜猎双卫。存档与区域补给分开。九项新专项通过，规则及边界见 [遭遇开发说明](ENCOUNTERS_V09.md)；完整路线需在新构建上验证，不复用改动前的通关结论。

## 五条支线及其结果

| 支线 | 完成条件 | 可见或可使用的结果 |
| --- | --- | --- |
| 未归的信使 | 在移动运输匣上取件，送往下层投递口 | 返程旧货梯载人上升 |
| 停工的修补机 | 取回扣件，清除维修点附近守卫，再交付 | 中央实体支撑立即接通；返程真正踏上支撑才解锁「接住坠落」 |
| 无名者索引 | 获取两处不同位置的记录 | 纪事记下送信的苇与修路的栖，结局追加对应记录；解锁「替城记住」 |
| 旧猎手的试炼 | 接受试炼后，不落地或受击换过三个不同锚点，再交付 | 返程肩台与「看破倒影」称号；不足三个不能交付，失败可继续尝试 |
| 最后一盏灯 | 收取灯芯，带到下一房的路标 | 携带时角色旁可见灯芯，交付后返程灯与实体落脚点出现 |

三项新成就均为外观称号，不增加战斗数值；总成就数为十八项。它们依据实际事件解锁，读取旧存档不自动补发虚构成果。

松钩默认向上借力，按住 S / 下方向时保留向下甩出的意图，用于连续下降和镜廊试炼。监炉者被配重反制时会同时解除已连到玩家身上的链，反击窗口不遗留牵引。

试炼记录的是已经接上的不同永久锚点，同一锚点重复抓取不会充数；未完成三个时，落地或受伤重置连续记录。完成三个后允许落地去交付。跨刷新恢复未交付试炼时，保留已接受状态并重新进行连续动作。

## 返程与故事兑现

取心后进入上行，部分预定平台坠落，原有永久锚点保留。货笼的停靠方向、镜桥的桥向与支线落脚点继续影响路线。完成信使任务的货梯可载人上行，维修支撑可作为落点，最后一盏灯提供局部可见路标。

选择复制目录时，永久锚点附近出现额外上行指引；选择原件则在纪事与结局保留完整证据。二者不替代安全基础通路，不追加英语标准答案。未完成索引时，结局不声称知道两台机器的名字。

背景音乐仍采用既有三阶段单曲循环，铭文不压低音乐音量。角色语音、钟鼓音效保持停用。休整灯改为较小的铜制灯座，减少对角色和落点的遮挡。

## 保存、失败与输入

铭文模式与纯动作模式现在都保存冒险快照，可从标题续行。切换关闭铭文后续行原冒险，保留词组和已有答题结果，不追加学习记录。新冒险重置当局进展；历史成就仍保留。

旧五区存档的检查点映射到对应的新区域入口，迁移房间进展但不捏造支线完成。新存档保存十五房标记、五条支线、桥向、记录选择、货笼停靠和护灯安全点。移动平台与角色的逐帧位置不被强行恢复到危险的半空。

四强化技能仍每次出题，错误、拼错、超时或放弃取消；无时间冷却、无免题续招。答题冻结伤害、移动平台、护灯与敌人轨迹，表现时间独立。普通攻击、移动、抓钩与普通机关不出题。

## 当前验证

完整回归发现并修复了超出引擎克隆上限的问题：改用 167 个固定显示槽、按镜头复用，并优先保留攻击对象额度。新场景 34 项与四技能 17 项专项通过，详见 [对象预算及证据边界](SCENE_BUDGET.md)。下面较早的房间/支线结果仅证明当时测到的逻辑，完整画面和投射物须以修复后的回归为准。

- 地图及迁移规则七项、成就规则十项、原词汇规则九项通过。
- 房间实机专项十四项通过，包含移动平台承载与暂停、答题冻结、护灯受扰返回、真实攻击切断回路、热流碰撞、桥向、纯动作下潜/返程续档和旧存档迁移。
- 支线实机专项七项通过，包含真实换钩、清理维修守卫、维修支撑落地、货梯承载、纪事及纯动作续档。
- 上述专项使用网络响应中的位置夹具隔离任务，实际交互、物理、碰撞和保存使用生产逻辑。它们不能冒充全路线真人试玩。
- 先前基础路线通过十五房及三形态 Boss，跳过全部支线；其证据版本早于最新支线与坠落平台细化。当前完整回归正在重新执行。
