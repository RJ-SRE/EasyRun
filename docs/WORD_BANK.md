## 来源与覆盖口径

1. 教育部教育考试院发布的[《全国大学英语四、六级考试大纲（2016 年修订版）》](https://www.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)，PDF 第 21–149 页词表。大纲只列词形，六级用星号标识，不提供中文释义。
2. [ECDICT](https://github.com/skywind3000/ECDICT)，固定提交 `ab22ad36302cafc6349a050e2b60894855208055`。采用其中词性、中文译文、拼写及 CET 标签；纳入该版本全部 `cet4` / `cet6` 标签条目。与旧版本“仅采用词元”的使用方式不同，当前分发中文译文节选，继续附带其 [MIT 许可](evidence/inscription-v1/ECDICT-LICENSE.txt)。
3. 原有 82 个词的人工题面保留；另外对 a、can、bow 等 21 个常见词指定游戏目标义项，避免直接采用技术缩写义或不合适的次要义。`microwavable` 的简短译文由项目补充。

PDF 声明收录 5,418 个词目，坐标提取获得 5,377 个主词行，**全部行都能映射到当前词库**。逐行映射见 [head-mapping.json](evidence/2026-10-26-wordbook/head-mapping.json)。并列拼写、同形异义行与派生词采用不同的计数单位；目前未完成对声明总数和物理行数的独立逐项核销，因此不宣称“经权威审校的全部 5,418 个词目”。本版不再限制于小样本，而是完整纳入已提取表行及固定字典的 CET 标记集合。

四个展开形式没有在固定字典中确认，未作为可接受拼写：`celcius`、`honourary`、`instalation`、`sobre`。相应规范词 `celsius`、`honorary`、`installation`、`sober` 均已包含。该差异公开记录在 [覆盖清单](../prototypes/runlab/data/cet-coverage.json)，不能为了让计数好看而接受未确认拼写。

主词等级优先使用大纲星号；派生词继承主词等级；额外字典条目使用其标签。四级／六级是来源范围，基础／全部／挑战是游戏筛选：默认长度 ≤6 为基础组，≥10 为挑战组，中间为第二组，原有人工分组优先。基础用第 1、2 组，挑战用第 2、3 组。这不是考试机构的逐词难度评分。

## 题目质量与变体

- 每题限定词性与目标中文义。保留原 82 条短语境，其余显示词性和“常用义”，不伪造例句。
- 新条目的两个干扰项优先同词性；排除目标的已记录义项、拼写变体、重复选项及明显字面重叠。规则用于减少冲突，不能保证所有近义、多义关系都被识别。
- 大纲明确并列的英美拼写进入接受列表；大小写不敏感。非单一英文字母的词条只出辨义题，避免要求玩家在战斗中输入空格、连字符或撇号。
- 自动验证覆盖、唯一性、三个不同选项、有效中文、变体和所有范围的容量；对常见词进行了定向修订。**8,815 个题面尚未逐条完成独立语言专家审校。** 后续可通过版本化义项修订修正，不会清空玩家历史。

## 可复现构建

常规离线构建只需要已入库的规范源数据，无须重新下载整个词典或安装 Python PDF 依赖：

```sh
bash scripts/with-env.sh node scripts/build-wordbank.mjs
bash scripts/with-env.sh node --test prototypes/runlab/test-inscription-core.mjs
```

输入：`prototypes/runlab/data/cet-source.json`、`cet4-curated.js`、`cet-meaning-overrides.json`。输出：网页直接加载的 `public/cet4-words.js` 和 `data/cet-coverage.json`。当前公共模块约 2.36 MB 未压缩，加载一次；战斗中不联网查词，也不调用 AI。

从原始材料重新提取的流程见 [提取脚本说明](../scripts/wordbank/README.md)。固定文件摘要：

## 记录与学习边界

预览不计完成，提示拼写不计独立回忆，超时与拼错分开记录；通关只确认本局真实答对的词。一次成功施放不等于掌握，稳定刻印也只是本产品的复习状态，不是考试能力认证。数据保存在当前浏览器来源下，可导入导出，无服务器同步。
