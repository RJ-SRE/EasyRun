# EasyRun / 裂隙 · 倒悬钟城 PRD

版本 v0.10，2026-10-25。当前交付分支 `main`，由 `feat/hunt-combat-v10` 保留历史合入。详细敌人、关卡、调参与美术规则见 [猎战重构](HUNT_V10.md)，验证结果见 [验收账本](planning/hunt-v10/IMPLEMENTATION.md)。[v0.9 PRD](PRD_V09_ARCHIVE.md) 保留为历史方案，其中机关、护送与支线设施已废止。

## 1. 产品目标

面向喜欢动作冒险、愿意在游玩中复习英语的成年电脑玩家。玩家从倒悬旧城向下潜入，以钩索、位移与战斗击破守心者，携带钟心向上撤离。成熟的哥特废城、残甲敌人与垂直追逐构成视觉和玩法主线。

先让敌人的行动带来战斗选择。玩家应能看清蓄势、锁向、出手与收势，使用高度、距离、绕背、破架和优先处理支援等方法应对。普通 J 仍能连击和击杀，但站桩连按不能持续打断所有类型。

当前交付一个五区十五段关卡、三场精英（四个体）、三形态守心者与返程追击。40 名普通敌人与 3 名返程追兵按遭遇布置。常规段允许绕行，精英承担三次进度检查，撤离路线不依赖机关。正式商业规模、学习效果和长期留存须另行真人验证。

## 2. 主循环

1. 开始页独立选择战斗难度与铭文设置，预览随机 30 词。可关闭铭文进入纯动作模式。
2. 沿固定建筑与锚点下潜。看敌人类型和起手，选择战斗、改变高度或绕行；区域入口和 Boss 前补给。
3. 击败裂甲执刑者、双生猎手、折翼审判者，再挑战三形态守心者。
4. 取得钟心后旧巡逻敌人退散，沿固定锚点向上逃离黑潮，越过少量追兵。
5. 结算真实成绩、成就和实际完成的词。未遇见或未答对的词不能自动计为完成。

死亡从逐段自动检查点继续，保留本局词汇结果与已击杀进度；Boss 死亡后重新开始完整 Boss 战。R 重开清除本局达成但保留词组与历史词册。存档在本机浏览器保存，继续时从检查点重建，不恢复半段攻击或弹幕。

## 3. 动作与敌人

基础动作：地面三连、挑空、空中追击、坠击、跳跃、二段跳、蹬墙、方向冲刺、钩索拉近与甩出。伤害判定与受击打断分离，技能须完成蓄势/执行/收势。

八类敌人：悬刃、短锋、壁弓、缚索、封脉、裂甲卫、棘背猎兽、缝魂师。新敌人各有独立六姿态图集与实际攻击轨迹。重甲正面护架可由 L 重斩破除或绕背；猎兽用跳跃和落点判断应对；支援者的单体连线受距离、视线、受击与死亡限制，不回血或复活。

三场精英在普通规则上组合能力：执刑者半血卸甲、双生接力与拆分、审判者独立预告二次俯冲。守心者有三个形态、七种招式，初次交战即可受伤，不需要外置钟锁。

战斗预算控制同时攻击数量，不能靠堆敌人形成无预警连续伤害。镜头、特效、攻击与答题状态应一致冻结/恢复，离屏实体保留逻辑，显示对象复用且不挤占技能投射物预算。

## 4. 铭文机制

- 每局从本地精选 CET-4 库随机抽 30 个不同词，支持开局预览、换组及基础/标准/挑战范围。学习结果保存在本机词册。
- U 蓄箭、L 蓄剑、I 治疗、Q 连环剑刀每次独立答题，Q 答对后才出招；没有答对后免题续招，没有技能时间冷却。
- 拼写题输入完整词；辨义题三选一，按 1/2/3。拼错、选错、超时或放弃取消本次技能。
- 普攻和位移不中断出题；被控制时沿用已有脱身规则。技能是否可以起手仍受当前动作状态约束。
- 作答冻结危险逻辑，表现层继续慢速运动。恢复后不补算冻结时的攻击，按本次答案释放或取消动作。
- **30 词是本局可选目标，不是出口门槛。** 更多有效战斗情境应自然提供施放理由，不能为凑词强制补题。一次答对不等于永久掌握。

## 5. 美术、音频、UI 与成就

旧铜、象牙裂甲、暗色残布与石砌建筑保持统一。靠轮廓、武器与起手辨认敌人，不放置巨大机关图标、控制台、档案底座或检查点装置。检查点自动记录，钩索标记保留必要可读性。

猎手手记提供五区短故事和八类敌人应对方式，主动打开暂停游戏。没有角色配音或对白音频。背景音乐开始/游戏/结束分别单曲循环，单词阶段保持正常音量；玩家主动暂停和静音仍生效。新增攻击反馈复用现有材质音效，不恢复钟鼓。

18 项成就包含行旅、动作、铭文与真实战斗表现。旧机关成就退出当前列表，增加破甲、断线、四名精英累计击杀；排练不计冒险成就，称号不改变数值。

## 6. 交付与验收

桌面浏览器与实体键盘为当前范围；网页宿主提供词册、音频、设置和成就，XBuilder `.xbp` 为可导入的纯动作工程。九种公开排练支持单独理解敌人。

必须通过：构建与语法、敌人实际伤害/反制、护架与技能答题交互、暂停/重试/续档、旧存档迁移、五区双向镜头、投射物预算、音乐连续性、正常和困难整局键盘路线。具体运行命令、断言与局限在验收账本逐项记录。

不包含账号、付费、云存档、联网出题、多人、触屏/手柄适配或新增章节。真人趣味性、自然 30 词覆盖、跨设备性能与长期留存不以自动脚本代替。
