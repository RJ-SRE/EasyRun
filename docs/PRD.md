# EasyRun / 裂隙 · 倒悬钟城 PRD

版本：v0.7 · 铭文远征，2026-10-25。桌面浏览器可玩的完整单关；合并五类忍者刺客、四技能与英语铭文。角色语音和对白继续关闭。

详细规则沿用 [铭文策划 v1.1](planning/inscription-v1/DESIGN.md)，实际交付、调参与差异以 [v0.7 实现说明](INSCRIPTION_V07.md) 为准。历史方案保留作决策记录，不等于当前全部功能。

## 1. 体验与范围

玩家是潜入倒悬钟城的持弦者。下潜、破除两道钟门、击破守心者双钟锁、取得钟心，再利用钩索向上逃离黑潮。动作、站位和敌人前摇决定生存；英语只参与关键技能的完整释放与受控脱身。

目标是喜欢动作冒险、愿意在短回合复习英语的成年电脑玩家。当前交付一个完整关卡和一个独立通道实验模块；不包含付费、账户、联网生成题目、角色对话、多人与新章节。学习收益、长期留存与商业表现仍需真实用户验证。

## 2. 开始、存档与结束

开始页可独立选择战斗难度（旅人/无畏）、词汇范围（基础/标准/挑战）、作答节奏（宽裕/标准/紧凑）及拼写提示（完整/渐隐/回忆）。可关闭铭文，进行纯动作冒险；排练场固定为纯动作。

每次远征从本地 CET-4 精选库随机抽 30 个不重复单词，支持完整预览和换组。预览不计完成；改词汇范围重新抽组，改节奏或提示不重抽。开始后锁定词池。

- 普通死亡：Enter 从休整灯继续，保留本局词汇进度。
- R 或铭文暂停面板“重开本局”：保留同一组词，清除本局达成，历史学习记录保留。
- 暂停后返回标题：保存词池、词汇进度、难度与休整灯位置。点击“继续上次远征”重新加载运行时，从休整灯安全重建，恢复血量及技能；不伪装成逐帧即时存档。
- 30 词是本局池和可选目标，完成主线即可通关。通关只确认实际答对的词，未遇见/未答对的不自动标成完成。
- 本机词册显示待斩、本局已斩、待复习和通关确认；可导出 JSON。没有账号或云端上传。

旅人：8 格生命、Boss 16 生命；无畏：5 格生命、Boss 20 生命，弹速与黑潮更快。两阶段 Boss、三段可选回声、失败续关和原战绩系统保留。

## 3. 动作与技能

| 输入 | 行为与边界 |
| --- | --- |
| A/D 或左右、空格 | 移动、二段跳、蹬墙；S+空格穿过普通平台 |
| E 按住/松开 | 抓锚点或敌人，牵引后甩出；方向键辅助选点 |
| J / W+J / S+J | 普攻三连 / 挑空 / 坠星；普通间隔 0.28 秒，每次腾空最多两次追击，空挥不能无限滞空 |
| K / Shift | 冲刺，W/K 上冲、S/K 下冲；可取消蓄势 |
| U 按住后松开 | 贯夜，3 秒冷却；短蓄 1 伤，0.55 秒满蓄后挑战。正确：2 伤、穿透至多两敌、首个命中留 3 秒裂印；错误：普通箭 |
| L 按住后松开 | 断潮，5 秒冷却；短蓄 2 伤，无连携满蓄进入挑战。正确：3 伤，可引爆裂印再加 2；错误：基础重斩 |
| I | 回息，5 秒冷却、消耗 1 余烬；静止引导至最后 0.15 秒时辨义。正确恢复 1 格；错误/超时/放弃返还本次余烬，冷却保留；正常战斗打断不退款 |
| Q | 连环剑刀，10 秒冷却、五段；前三击正常，第 4 击前一次辨义，正确后最后两击连续释放，错误跳过两击后收势。没有有效敌人时不强行出题 |
| F（被链钩牵引时） | 可选铭文解链；原来的 J 斩链、E 抓锚、近身脱离仍可用 |
| Esc / Enter / R | 暂停 / 开始或续关 / 重开；题中 Esc 打开铭文暂停面板，不吞掉答案 |
| T、排练中 1–6 | 五类刺客单练与组合排练；不计词汇和冒险战绩 |

贯夜的自动锁定只选择屏幕内、540 单位内、无遮挡且可伤害的目标。箭出手后直线运动，答对不自动命中、不穿墙、不越过 Boss 钟锁。

**裂印连携**：满蓄断潮检测到有效范围内的现有裂印时，直接释放，不再出第二题。提示出现后目标失效，则降为基础重斩，不在挥空后补弹题。只有实际命中才消耗裂印。

余烬上限 2、开局 1，每 4 次有效伤害凝成 1；空挥、护盾和格挡不计。铭文不重置空中追击额度，不免费恢复技能冷却。

## 4. 敌人与控制

| 敌人 | 动作身份 | 铭文关系 |
| --- | --- | --- |
| 悬刃 | 飞刀、空中掠身、重新锁向追刀 | 可蓄箭反制；答对后仍需实际命中 |
| 短锋 | 三段近战；交替撤步、有限护刃、飞踢和低扫 | 重斩破势；轻击格挡和背面破绽保留 |
| 壁弓 | 壁龛射箭、蹬墙腾空放箭、沿弧线返回 | 锁定排除遮挡目标；箭矢可被斩断 |
| 缚索 | 低位扫链接预警抛钩；可行动牵引 | F 主动辨义；成功反制，失败也有界脱离，不重复拉回 |
| 封脉 | 绕位、锁向、突进擒拿 | 先承受 0.7 模拟秒硬控，再辨义；两种结果均脱身，成功给更长反击窗口 |
| 守心者 | 短锋精英、两轮双钟锁 | 英语不能替代拉断钟锁或绕过半血重锁 |

最多两名敌人同时起手/执行/身法，其中最多一名近身控制者。控制中不启动新攻击，已飞出弹幕不能伤害被擒拿者。封脉只在有支撑的平台上发生，不传送或推下悬崖。铭文释放后给约 0.4 秒保护，封脉铭文结束后 10 模拟秒控制免疫；纯动作保留原 2 秒。

## 5. 铭文与节奏

顶部中央的“断环刻印”接管键盘：宽度上限 480px，短屏 440px；左侧破损钟环显示剩余时间与当前技能，右侧只显示单词、语境及作答。拼写以逐字亮起的刻痕反馈，忽略大小写，完整正确自动确认，允许退格修正；辨义使用带 1/2/3 键号的三枚窄签，支持数字键、鼠标及聚焦后的 Enter。主角、落点和两侧生命 HUD 保留可见。

贯夜与断潮在拼写和辨义之间交替；回血、大招终式、解控只用辨义。没有全局定时弹题，也没有通关出口补课。正确或错误都立即提交技能结果，不等待提示动画结束；结果提示成为不拦操作的余影，正确约 0.46 秒、错误约 0.8 秒淡出。

进入聚焦时**冻结位移、伤害判定、敌人、弹幕、裂印和所有冷却**，独立表现时钟让装饰粒子、蓄力姿态和镜头阻尼由常速渐缓至约 12%。这是受保护的战斗冻结配合视觉慢动作，不能称为全场物理慢动作。镜头在约 0.32 秒内轻推 2.5%，角色周围断环与尘光继续运动，正确字母化为流光汇入武器。这样玩家打字时不会坠落，也不能刷冷却。完成后释放旧按键，答题字母不能作为动作缓冲，新按键立即接续；镜头和局部释放弧光在恢复操作的同时退场。隐藏窗口、输入法合成、主动暂停同时暂停题目、表现动画和聚焦音效。

初步体验目标是前台专注占比 15%–25%，超过 30% 应调整遭遇和题目密度；这是待真人验证目标，不是本轮自动测试已证明的结果。实际前台游玩与聚焦时间保存在导出的词册数据中，主界面只显示待斩与完成状态。

## 6. 视觉、声音和运行边界

沿用旧金属、深色遗迹、暖铜光的成人幻想风格。敌人共 42 个关键姿势；主角有蓄弓、放箭、回息、连环刀光、裂印、命中与重斩效果。关键帧交叠与连续位移共同表现动作，未引入骨骼动画。

铭文界面使用断环、刻痕、窄签和斜切铜牌，避免整屏宽的大题框。开场词汇设置收为 292px 的侧挂铜牌（短屏 270px），降低主标题尺寸，留出钟城景深；随行词册为 600px 上限的双列册页，三十道刻痕对应完成状态。战斗聚焦保留局部、连续的能量运动，不加入全屏白闪；减少动态效果与系统减少运动设置关闭镜头推近及网页粒子。

82 个本地动作/材质采样与环境音乐；可独立调音量或静音。铭文接管时旧声音以 120 毫秒淡出，接入低音张力和逐字递升的短泛音；恢复时关闭聚焦声并播放本次释放。聚焦声受音效音量、静音、暂停与窗口可见性约束；没有语音、台词、人声发力、英语朗读或网络音频请求。提供减少闪光和界面动效选项。

主交付是配套网页 + spx；单个 `.xbp` 默认纯动作，包含角色/场景/战斗，不包含网页词册、音频混音或浏览器存储。独立五通道实验在 `/passages.html`，其新钩索效果和空间音频另行保留，没有强行混进两个物理运行时。
