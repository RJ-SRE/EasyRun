# EasyRun / 裂隙 · 倒悬钟城 PRD

版本：v0.5，2026-10-24。单关卡战斗版本；角色语音与对白按用户要求暂时移除。前版：[v0.4 纵向冒险](PRD-v0.4.md)、[v0.3 风机墓场](PRD-v0.3.md)。

关联：[本次范围与验收清单](COMBAT_V05_PLAN.md)、[技术设计](TECHNICAL_DESIGN.md)、[测试](TESTING.md)、[素材](ASSETS.md)。

## 1. 产品体验

一座仍在执行旧职责的机械钟城。玩家作为持弦者潜入井底，破除钟锁、取得钟心，再沿永久锚点返回光里。战斗建立在上下移动、挑空和钩索接力上；选择攻击方式同时也是选择落点。

目标玩家是喜欢动作、机械幻想和氛围探索的成年电脑玩家。当前通过动作、场景和音效表达角色，不启用角色语音或对白。商业价值与留存仍是待真人验证的假设。

本次用户在讨论多种攻击、连招、动作、声音和英语角色对白后授权“闭环规划好需求，然后进行开发完整”。交付限定现有单关卡内的完整体验；没有扩展付费、联网生成对话、多人或新章节。

## 2. 完整流程

开场选择旅人/无畏，也可进入排练场。冒险下潜经过两道实体钟门：分别击破织缆者与重甲钟卫才可继续下降。井底 Boss 有两轮左右钟锁；钩近吊环破锁后本体受伤，半血重建钟锁。击败 Boss 得到钟心、恢复资源，返程敌人出现，部分平台坠落，黑潮向上推进。返回井口左侧休整灯后结算。

保留检查点、失败续关、整局重开、三个可选回声、本机战绩与 JSON 导出。关卡高度约 3,590 世界单位。旅人生命 8/Boss 16；无畏生命 5/Boss 20，弹速和黑潮更快。

## 3. 动作与输入

| 输入 | 动作 | 用途 |
| --- | --- | --- |
| A/D、左右 | 移动与空中调整 | 选择进攻方向和落点 |
| 空格 | 跳跃、二段跳、贴墙蹬跳 | 接续路线 |
| E 按住/松开 | 牵引锚点、重敌；松开甩出；轻敌拉向自己 | 位移接力、钩近斩击 |
| 方向 + E | 方向辅助选点，S 偏向下方 | 475 单位内自动高亮目标 |
| J → J → J | 地面切线、返刃、断环三段 | 前两击 1，终结击 2；终结击击退 |
| 空中 J → J | 两段空中追击 | 延缓下落并维持敌人浮空 |
| W + J | 挑空 | 轻敌与主角一起升空，接 J 或 E |
| 按住 L → 松开 | 重击；0.55 秒起为完整蓄力 | 2/3 伤害，破甲、击退，轻敌可撞伤其他敌人 |
| S + J（空中） | 坠星 | 向下击穿、命中反弹，落地冲击 |
| K / Shift | 冲刺，W/K 上冲，S/K 下冲 | 躲避和连招取消 |
| Q | 断弦 | 消耗 60 弦能，范围 3 伤害；短时保护 |
| S + 空格 | 穿下普通平台 | 钟门关闭时仍不可穿过 |
| Esc / Enter / R | 暂停、继续或检查点续关、完全重开 | 暂停冻结模拟并停止音效 |
| T（开场/暂停/结算） | 排练场 | 四种守卫重生，可练动作，R 返回冒险 |

攻击有起手、有效帧和恢复；伤害在挥击帧结算。0.20 秒输入缓冲允许提前接招，J 长按不自动连发。轻击有效帧之后可接位移；重击恢复更长，不能任意用冲刺抹去失误。击杀恢复冲刺与二段跳。钩近轻敌不会把主角强行拉向它；重型敌人与锚点继续承担牵引目标。

本版连招是动作组合，不要求死记复杂按键串，也不把成功限定为某条固定连段。

## 4. 敌人和故事感

| 敌人 | 性格与视觉 | 攻击与应对 |
| --- | --- | --- |
| 提灯者 | 瓷面、旧披风、提灯；过度热心的救援机 | 瞄准弹与锁定方向冲撞交替；可拉近、挑空 |
| 织缆者 | 纺锤瓷面、细铜机械肢；执着修复秩序 | 三发扇射与瞄准绊索交替；绊索可被斩断并使其露出破绽 |
| 钟卫 | 铜钟重壳、瓷面、垂摆；日程不容打乱 | 扇射与向外扩散的钟波交替；普通轻击不能打开闭合重甲，重击/坠星/钩斩可破甲 |
| 模仿侍从 | 新的细长机械鸟、双刃、四个独立姿态 | 最近玩家用冲刺或重击则模仿突进，其他情况模仿近身斩；招式之后失衡，以动作透露笨拙 |
| 末代钟卫 | 双悬索保护的巨大铜钟 | 两轮破锁、半血加速；扇射与钟波交替，不接受位移击退 |

敌人预警约 0.8 秒。攻击方向在预警时锁定；预警、出招、受击、恢复分别反馈。重击掷出的轻敌可撞伤另一敌人；钟波可破坏附近织缆者的绊索。位移后敌人返回巡逻区域，避免守卫被永久拖离关卡。

## 5. 当前关闭角色语音与对白

2026-10-24，用户明确要求“先关闭语音包，把当前游戏的对话去掉”。本项覆盖此前的声音制作与对白接入计划：

- 主角与所有敌人都不播放角色语音、台词或人声发力包。
- 删除中英对白字幕、说话者名称、对白频率、配音音量与字幕设置。
- 游戏入口不导入对白脚本/调度器，不请求旧系统语音或新试音包；浏览器里残留的“健谈”等旧偏好不会启用对白。
- 保留动作音效、敌人攻击预警、环境音乐、操作提示、关卡目标与结算界面。
- 既有导演稿和试音留作制作资料，当前不继续生成或接入。后续恢复语音须以新的产品决定为准。

## 6. 美术、动作和声音

继承绘制的钟城、雕花平台、12 帧跑步和 8 个基础动作姿态，新增 12 个战斗关键姿态与 4 个模仿者姿态。不同斩击有不同方向的弧光；蓄力铜金环、受击偏移、碎片、短命中停顿、钩索链、雾尘与相机共同表达动作。

声音只保留音效、环境音乐两个可保存音量。刀风按连段变化，瓷面/铜壳有不同撞击，重击带低频，钩索和弹反有独立提示。页面保留一键总静音。

排练场使用完整练习平台，四类敌人可重生，但不豁免受伤；失败后可重进。练习记录不计入冒险战绩。

## 7. 验收与边界

新增机制由真实键盘输入测试，排练场是公开玩法入口，无隐藏写状态接口。测试包含连段、长按、挑空、蓄力、取消、重甲、绊索、敌人交替、模仿、无对白资源请求、旧偏好兼容与 56 个动作/材质音频解码；同时回归两档完整路线、死亡/重试、暂停/指南/设置、旧场景和导出。

准确执行结果见 [测试记录](TESTING.md)。尚未完成真人手感与趣味性验证、跨设备性能、手柄/触屏、编辑器往返保存、正式发行授权与商业指标验证。`.xbp` 包含核心玩法和场景；动作音效、音乐与界面在配套网页中。
