# v0.16.4 · 独立工程包战斗 HUD

> 后续 v0.16.5 已按反馈移除下表中的右上与右下常驻信息；此文保留 v0.16.4 原始设计与验收记录。当前说明见 [XBuilder 导入版](XBUILDER_NATIVE.md)。

2026-10-30。本轮只完善 `.xbp` 的战斗信息，不改网页版玩法，不迁移存档、成就或单词算法，不推送远程。

## 信息布局

| 位置 | 内容 | 显示条件 |
| --- | --- | --- |
| 左上 | 原有生命、两枚余烬、每四次有效命中的恢复刻度、铭文进度 | 战斗与答题；铭文进度下移，点击与 Tab 均可打开词册 |
| 左下 | 原有 76×28 技能卡，保留冷却环和 0.1 秒倒计时 | 战斗与答题 |
| 技能卡第二行 | 蓄力、满蓄、待刻印、回息中、连斩中、生命满、缺余烬、需落地、受缚 | 根据实际状态切换；普通就绪继续只用细线表示 |
| 技能上方 | 封脉、缚索、弓箭锁定、空中追击耗尽、破架等短提示 | 存在相关状态或事件时显示，事件持续 1.6 秒 |
| 右上 | 分数、有效战斗用时、十米刻度深度；上返增加距黑潮距离 | 正常战斗；答题隐藏 |
| 右下 | 当前城区与下潜/上返阶段，检查点、击破数、回声收集 | 正常战斗；排练显示当前敌人类型与 1–9 序号 |
| 顶部中央 | 守心者血条、三形态名、招式和蓄势/方向锁定/出招/换位/收势状态 | 决战且 Boss 存活；答题时隐藏，题目结束恢复 |
| 暂停/结算 | 用时、分数、击破、连续击破最佳、回声；结算另含倒下与检查点 | 对应菜单 |

暂停、词册、标题和结算都隐藏战斗专用层。没有恢复原先删掉的常驻大按钮和通用操作提示。全部元素位于原有 960×600 逻辑画幅，继续按比例容纳窗口。

## 规则与可读性

- HUD 只读取游戏状态，不改变攻击、判题、资源、冷却或敌人 AI。
- 回息的不可用原因按当前规则判断：空中需先落地，地面再判断生命与余烬。正在回息/答题时，显示对应进程；已消耗余烬不会误显示为“缺余烬”。
- 技能在等待铭文时显示“待刻印”；答错后回到实际状态；成功后使用原有 3/3/3/5 秒冷却。
- Boss 提示使用当前状态，不提前预报下一招。血量按百分之一显示，三分之一标记与三阶段转换对应。
- 连续击破沿用游戏中的 `combo` 统计，不把普通攻击次数冒充连击数。
- 事件提示用文字和颜色共同表达，封脉与缚索状态优先，重复同一事件不会逐帧重启动画。
- 分数与时间是现有有效战斗时钟；答题与暂停不增加计时。深度/黑潮距离显示到十米，属于显示精度，不改变实际移动与危险判定。

## 实现与性能预算

`NativeCombat.spx` 提供状态转换与必要动态文字，打包后进入既有 `NativeLogic` 控制器。`belfry-native-combat.mjs` 在构建时栅格化固定标签、血条与余烬刻度。

- 新增 **4 个原始精灵**：余烬、Boss 标签、Boss 血条、条件提示；这四个图形精灵不使用克隆。
- 技能仍使用原四个精灵；目标栏仍使用原精灵，仅补充造型与状态索引。
- 新文字使用现有的动态字形池，上限仍为 160 个。探索时常见字形数量从旧版的 7 个增加到约 28–31 个，并非所有新增信息都没有实例成本。计时按整数秒、深度按十米更新；分数等只在值改变时重建文字。镜头移动只同步位置。
- 答题时隐藏次要统计和 Boss 栏，把字形预算优先留给单词、释义和选项；词册沿用已有分页预算。
- 保留 v0.16.3 控制器分离、紧凑词库、事件式钩索/攻击线，以及原始精灵位置/造型写入缓存。

新包约比 v0.16.3 增加 2.8 MB，主要是预渲染 HUD 造型。增加的信息与文字仍有运行成本，性能结论以同机对照为准。
