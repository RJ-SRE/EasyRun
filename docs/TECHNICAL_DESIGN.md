# 倒悬钟城技术设计

v0.4，2026-10-24。旧场景的参数保存在 [v0.3 技术设计](TECHNICAL_DESIGN-v0.3.md)。

## 文件入口

| 文件                                            | 职责                                                           |
| ----------------------------------------------- | -------------------------------------------------------------- |
| `prototypes/runlab/belfry-level.mjs`            | 平台、永久锚点、敌人、回声、检查点的唯一关卡数据源             |
| `build-belfry.mjs`                              | 图集导入、注册、绘制资源、场景排序、生成 spx 初始化与清单      |
| `spx/belfry/main.spx`                           | 世界状态、敌人 AI、资源、胜负、检查点、钟锁、黑潮和遥测        |
| `spx/belfry/Hero.spx`                           | 输入、辅助选点、钩索、跳跃、冲刺、斩击、坠星、碰撞、动画和相机 |
| `Enemy/Anchor/Echo/Rope.spx`                    | 从世界状态渲染实体；不另行决定碰撞结果                         |
| `Bolt/Particle/Pulse/Slash/Trail/PoseBlend.spx` | 飞弹、瞬态效果及跨重试生命周期                                 |
| `public/belfry.html/.css/.js`                   | 引擎加载、界面、合成音频、本机战绩；不运行战斗规则             |
| `art/belfry/`                                   | 原始图、提示词和可重建图集                                     |
| `test-belfry.mjs`                               | 页面、暂停、钟门、死亡、检查点、重开及存储验证                 |
| `test-belfry-route.mjs`                         | 键盘路线、两阶段核心战、返程；可验证黑潮失败和续关             |

默认 `/` 为倒悬钟城，`/belfry.html` 是同页明确入口。`/rupture.html` 为风机墓场，`/legacy.html` 为两个早期原型。

## 构建、运行、测试、打包

继续使用锁定的 Node 24.22.1、pnpm 11.9.0、spx 3.3.0、Playwright 1.64.1。没有引入服务端账号或新的云依赖。

```sh
bash scripts/with-env.sh pnpm game:build
bash scripts/with-env.sh pnpm game:dev
bash scripts/with-env.sh pnpm game:test
MODE=1 bash scripts/with-env.sh node prototypes/runlab/test-belfry-route.mjs
bash scripts/with-env.sh pnpm game:package
```

生成目录、导出包、运行 JSON 与拆帧目录均忽略，原图和源代码纳管。构建期间由 Chromium 完成 PNG 图集导入，原图保持不变。平台共享一张纹理，通过克隆按关卡宽度缩放，避免为每个平台加载大图。

场景生成的克隆必须由 `main.spx` 在 `initLevel()` 之后创建。不能在精灵自己的 `onStart` 中立即读取关卡数组长度：某些启动顺序下数组尚未初始化，会形成“有碰撞而没有平台绘图”的问题。

## 主要规则与参数

- 视口 960×600，世界高度约 3,590；页面按比例适配，支持全屏。
- `phase`：0 开场 / 1 运行 / 2 通关 / 3 失败 / 4 暂停。
- `segment`：0 下潜 / 1 核心战 / 2 返程。
- 主循环每帧先更新角色，再更新世界；模拟 dt 上限 0.035 秒。命中停顿短暂冻结模拟，游戏时间不等同于墙钟时间。
- 跑速 ±300；普通重力 1250；空中最高下落速度 900，坠星 1100；跳跃初速度 560。
- 跳跃缓存 0.13 秒，离地宽限 0.12 秒；支持二段跳、贴墙缓降与蹬跳。
- 钩索距离 475；根据方向、距离、敌人类型及核心战钟锁优先级选择并高亮目标。持有时径向牵引与收绳，松开保留动量并助推向上；接近锚点可自动释放。
- 钩向普通平台下方允许穿过单向平台；关闭钟门与井底仍保持实体碰撞。
- 冲刺 0.18 秒，冷却 0.8 秒，短暂无敌；击杀重置冷却。
- 普通斩击 1、回钩斩/坠星 2、断弦 3 点伤害。核心双锁闭合时均不能损伤本体。
- 飞弹与玩家相交时先检查斩击范围，避免同一帧“已弹反仍受伤”。
- 普通粒子最多 90，另有有限数量的绳段、敌人、护罩、残影和飞弹；所有瞬态对象带 `attempts` 防止跨局残留。
- 主循环约 70ms 输出一次 `@state`；事件使用 `@event`。宿主读取，不反向修改战斗状态。
- 黑潮：旅人 29、无畏 43 世界单位/秒；返程检查点重新开始黑潮计时。
- 存储键 `easyrun-belfry-v1`，最多 50 条记录。导出由用户点击触发。

## 美术与声音

主角沿用 12 格跑步和旧基础姿态，新增 8 格动作图集。图集分割使用显式行边界和重心注册，动画短过渡；这是逐帧图片动画，不是骨骼动画。敌人以浮动、轻旋转、预警亮度和受击闪光呈现状态。

背景、敌人、平台、角色是 PNG；锚点、绳索、护罩和粒子是项目生成的 SVG。场景与战斗特效在 spx 中，页面只负责 UI 层受伤边缘、文字和声音。

浏览器 Web Audio 合成铃声、噪声风切、撞击及氛围音；声音开启依赖用户手势。暂停时音量渐隐；声音开关、页面隐藏和加载失败需要保持一致。

## 包与边界

`game:package` 生成四个 XBuilder `.xbp`。倒悬钟城包内含玩法、美术与场景特效；独立网页的 HUD、音乐、指南和本机战绩不包含在 `.xbp` 中，完整体验以本地网页为准。

本机 Chromium 完成测试。尚未验证 Safari、移动性能、原生发布、编辑器往返保存或长时间稳定性；没有将页面 rAF 间隔作为引擎实际 FPS 的证明。
