# 倒悬钟城：暗夜刺客声音重设计

> 当前规则（2026-10-25）：角色语音继续停用，并按用户要求取消钟鸣、鼓点与技能低鼓叠层。环境使用轻柔气流，保留刀风、弓弦、钩索和接触反馈。下文的演员方向、钟壳共鸣等为历史制作提案，不覆盖现行规则。

> **当前决定（2026-10-24）：用户要求先关闭语音包，并移除游戏中的对白。以下声音设计/计划保留为历史制作资料；当前游戏不启用角色语音、对白字幕或对白设置，也不继续批量制作。**

2026-10-24，设计版 audio-v06。用户已选择：**冷静的暗夜刺客，低声、克制、干燥幽默**。

本次已完成声音方向、34 句双语台词及逐句表演指令、18 组音效/发声需求、10 句试音顺序。**新配音尚未录制或生成，运行时仍使用原有声音。** 本文的参数、预算与触发规则是待实现设计，不是已经通过听感验收的结果。

生产清单：[声线与角色](../production/audio-v06/voice-brief.json)、[双语台词](../production/audio-v06/dialogue.en-zh.json)、[身体声与音效](../production/audio-v06/efforts-sfx.json)、[试音顺序](../production/audio-v06/audition-order.json)。

## 1. 当前问题与重设计目标

用户反馈“浓浓的机器人味，一点刺客风格都没有”。检查本地生成脚本与播放代码后，能确认以下实现事实；这里没有把代码检查当成实际听音评审：

- 44 个现有片段来自 macOS `say`，使用 Daniel、Samantha、Reed、Fred、Eddy 等系统音色；生成时主要指定语速，随后加滤波、回声与响度处理。脚本没有逐句表演控制。
- 动作声音主要是随机噪声扫频和非谐波振荡器。不同攻击虽有参数差别，但缺少衣料、皮革、拉绳受力、瓷裂等独立的材质录音。
- 基于技能事件安排笑话，容易出现动作刚完成，角色又用较长的一句话解释它的情况。当前 `hookcut` 台词还会在结果发生后询问要选哪种方式，语义时机不对。
- 对白安全条件只用部分台词的 `long` 标记区分。例如较长的 `h-care` 没有此标记，不能用它保证所有探索语句在危险到来时都会退出。

新目标是：玩家能从声音辨认动作、敌人和角色状态；持弦者像身边一位警觉的同伴，句子有说出口的原因。危险期间让玩家听见信息，安全间隙才显露人格。

## 2. 持弦者的声线与表演

声线暂按成年偏低男中音选角，轻微英式语感，发音自然清楚。低中音区保留少量粗粝与呼吸，音高不靠后期强行降低。面具感优先通过角色行为、细小衣料声和很轻的空间反射表达。

| 状态           | 听起来怎样                     | 表演方法                                         |
| -------------- | ------------------------------ | ------------------------------------------------ |
| 观察、潜行     | 靠近同伴低声交代，仍在听四周   | 轻字头、短收尾；有声讲话，必要时才耳语           |
| 交战、紧急     | 简洁、明确，身体正在工作       | 指令可提高音量；动作以短吐气和呼吸代替台词       |
| 脱险、重试     | 收敛的疲倦与信任               | 停半拍，先把气喘匀；不挖苦玩家失败               |
| 看见旧世界遗物 | 发现具体细节后，才想到一点往事 | 允许迟疑；长句分成两个念头，避免总结人生的宣讲感 |

角色不会始终用一个神秘低音讲话。紧急时听清“Left. Move.”比维持低声更重要；“Easy. I've got you.”应有明显的温柔变化，但仍是同一位角色。

原创声线描述已保存在 `voice-brief.json`，可以直接交给演员或可控语音工具。参考电影中的亲近感、留白和动态，不指定复制某位演员的身份声线。

## 3. 语言风格与样例

战斗短句一般 1–5 个词；危险后允许一句冷幽默；探索对白与真实可见对象绑定。句子不按技能按钮一一配满，不把空白填成解说。

| 情境               | 英语与中文                                                                                                        | 表演指令                         |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 初入钟城           | **Keep close. Let the bells do the talking.** 跟紧。让钟声替我们说话。                                            | 贴近同伴，后半句像一个实用判断   |
| 左侧确有威胁       | **Left. Move.** 左边。走。                                                                                        | 突然清晰，短促，约 0.8 秒        |
| 两条路线均可用     | **The cable. Or the guard. Your call.** 切缆线，还是拿守卫借力？你定。                                            | 在行动前说；路线失效就放弃该句   |
| 危险跳跃后安全落地 | **Next time... a floor.** 下次……找条有地板的路。                                                                  | 先恢复呼吸，半拍干燥的幽默，不笑 |
| 重击收场           | **So much for subtlety.** 这下可够隐蔽的。                                                                        | 确认安全后自言自语，反话轻轻落下 |
| 低血量后进入安全处 | **Still here. Breathe.** 还在。呼吸。                                                                             | 第一半句对自己，第二半句对玩家   |
| 接住钟心           | **Easy. I've got you.** 别怕。我接住你了。                                                                        | 放下戒备的一瞬间，温柔但不煽情   |
| 观察无人守候的灯   | **They left the light on. Someone must have thought we'd come back.** 灯一直亮着。一定有人以为，我们还会回来。    | 第一念头是看见，第二念头才是感触 |
| 观察弃置的岗哨     | **I wonder who told it to wait. I wonder if they ever said how long.** 我在想，是谁让它等的。有没有说，要等多久。 | 迟疑、体谅；不配成预告片独白     |

完整清单包含 18 句主角与四类敌人各 4 句。标注 `existing_event: false` 的条目需要新情境检测；`true` 只说明已有同名事件，不代表已经接上该说话者。所有 `audio_file` 当前为空，不能把脚本当成成品语音包。

## 4. 敌人的声音人格：尖锐、恐怖、像有生命的异物

2026-10-24 用户进一步明确：敌人可以尖锐、恐怖，要发挥想象力，拒绝机械和机器人声音。本节替换先前偏“旧工作人员”的声音方向，主角仍保留冷静暗夜刺客风格。

新的声音叙事设想是：**躯壳还在工作，里面的执念已经变了。** 外形仍可使用铜、瓷、缆线；听觉让玩家感到里面困着会渴望、恐惧和捕食的东西。这个设想不代表游戏已经新增灵魂或鬼怪剧情。

| 敌人                   | 声线与发声动作                                                               | 表演变化                                             | 新台词                                                               |
| ---------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------- |
| 提灯者：幽甜的引路者   | 成年偏高、细薄的软声，带着不合时宜的微笑；追逐前细长吸气突然收住             | 发现玩家时像在安抚，攻击时暴露占有欲，灯灭时真的害怕 | **There you are. I heard you breathing.** 找到你了。我听见你呼吸了。 |
| 织缆者：巢中的缝合者   | 干涩、尖窄的齿间低语，舌颚轻响夹在词与词之间；受挫时某个音节突然向上折       | 缝合时专注得近乎温柔，线被切断后短促失控             | **Hold still. I can stitch that shut.** 别动。我能把那儿缝上。       |
| 钟卫：守着葬礼的哀鸣者 | 粗低气声里有压住的哭腔；重要句尾可接一层细高、无词的哀声                     | 护甲完整时宣判，破甲后露出被留下的恐惧               | **Kneel.** 跪下。／**Don't leave me here.** 别把我留在这里。         |
| 模仿侍从：窃声者       | 开头学本作原创主角的语气，停顿略长，尾词滑回尖细而兴奋的本声；偶尔笑得早半拍 | 熟悉的安慰突然成为诱捕，失手时认真地困惑             | **Keep close... closer.** 跟紧……再近一点。                           |

每一类都有发现、预兆、受伤与崩解的发声方向。提灯者受击时微笑裂成尖叫，随后又强行温柔；织缆者被毁掉作品会说“No. No... I made that.”；钟卫粗声里漏出一瞬细哭；模仿者听到自己的痛呼，会问“Was that... mine?”。

尖锐片段要短，角色低声、失声和突然收尾也承担恐怖感。四类的音区和节奏不同，不能全部做成持续高音尖叫。高强度尖声需要控制刺耳感，手机扬声器上仍应辨认预警和台词。

制作上优先自然表演：呼吸、舌颚声、齿间发声、短破音、悲鸣与气息失稳。人声主体不使用声码器、规则电子颤音、数字故障切片或统一金属滤镜。钟卫的双声来自独立表演的无词尾声；模仿者分句变换自然发声状态，保持一个可懂的句子。金属撞击、关节运动与钟响继续作为物体音效单独存在。

这轮重写了原有 16 条敌人台词与逐句导演指令，总台词数仍为 34；新增 24 个敌人非语言发声变体需求，尚未制作声音。

## 5. 身体声与技能音效

身体声独立于对白：轻击呼气 6 变体、重击发力 4、钩索吃力 3、硬落地 3、受伤 4、恢复呼吸 2，共 22 个主角待制作变体。另有四类敌人各 6 个非语言变体：预兆、受伤、崩解各 2 个，共 24 个。连续三连最多选一处轻发力；普通跳跃和轻落地以衣料、鞋底为主。身体声不能与主角说话叠成两个同时发声的人。

| 动作      | 时间结构与层次                                          | 音色目标                                             |
| --------- | ------------------------------------------------------- | ---------------------------------------------------- |
| 轻击三连  | 衣袖/皮革带动 → 短刀风 → 命中时加材质层 → 快收势        | 第一击紧、第二击薄而快、第三击更有重量；落空不加撞击 |
| 钩索      | 卡扣释放 → 钢丝抽出 → 目标接触 → 受力绷紧 → 甩出回卷    | 听得出绳索真正抓住并受力；拆成五个可取消事件         |
| 挑空/追击 | 短发力 → 自下而上的切风 → 接触 → 空中衣料延续           | 保留动作方向，避免每次都是同一个“嗖”                 |
| 蓄力重击  | 皮革拉伸、绷弦 → 吸气 → 释放短发力 → 接触低频与材质碎裂 | 低频只强调命中瞬间；不用通用爆炸声代替重量           |
| 冲刺      | 贴身衣料、短气流位移                                    | 利落、窄、快；没有持续电子哨声                       |
| 断弦      | 极限绷紧 → 断裂瞬态 → 压力释放 → 铜件余振               | 释放前世界声轻退约 40ms；危险提示持续可辨            |
| 命中瓷面  | 细硬接触、短裂纹、零散碎片                              | 普通命中与彻底破裂分开                               |
| 命中钟壳  | 钝的铜击、局部空腔、短尾响                              | 挡住、击中破绽、破甲有区别                           |

刀刃、衣料、瓷裂等应采用录制或生成的可用采样，保留 3–6 个自然变体；程序噪声可作补层。对关键杀招只在少量真实命中上保留宽动态。

## 6. 触发节奏与混音规则

以下是首轮实机调音的起点，可以依据试听修订：

- 对白明确分 `warning / combat / aftermath / story / reflection`，不再靠“长不长”猜情境。
- 常规完整句之间至少 25–40 秒；健谈档 15–25 秒；安静档只留关键剧情。关键剧情可突破常规冷却，但要避开危险提示。
- 普通动作不必产生对白。战斗短句每次遭遇最多 1 句；幽默每次遭遇最多 1 次，并放到确认安全后的 1–3 秒空隙。新遭遇以敌人参与战斗的集合与离战时间定义，不能按每次命中重置。
- 同一句整局不重复，常用警告采用变体和 10 分钟重复间隔。剧情与探索每局一次。重试不立即重播刚听过的长段。
- 探索句要求相关对象在视野中，玩家停留、低速，连续安全至少 6 秒；最早相隔 45–75 秒。无对象触发时保持安静。
- 警告候选超过 0.5 秒、战斗候选超过 1.2 秒就丢弃，绝不在敌人已死后补播；警告方位与目标在播放前重验。
- 有危险时暂缓幽默和探索。新预警、受伤、暂停、重试、隐藏页面都能让它们短淡出；不在恢复后自动从头复述。
- 首轮调音中，同一听觉区域最多一个高强度尖声主体；其他敌人用较轻气声与物体声表达。两次高声之间留出低声/无声段，避免持续刺耳。
- 说话者并发上限 1。主角对白期间不另播主角发力；危急身体反应可打断闲聊。敌人的身体声依然存在，并限制并发与距离。
- 优先顺序：危险信号 → 关键接触/受伤 → 短指令 → 身体声 → 叙事/闲聊 → 音乐环境。对白不能压低危险信号。
- 对白时音乐建议下降约 3–5dB，环境轻退；关键命中保留。采用 40–80ms 进入、约 250–400ms 恢复的避让作为首轮调音值，不瞬间开关。
- 人声保留干声；空间单独处理。近景主角在中央，远处敌人的声像与距离反映位置，封闭钟室与开阔井道可有不同短反射。
- 混音最终留峰值余量，建议先以真峰值不高于 -1dBTP 检查；这只是本项目工作目标。不要把所有短片段强行压成同样响度。
- 音效、音乐、对白和字幕偏好继续独立保存。切走窗口后既无残留对白，也无上一局的异步解码片段突然开始。

## 7. 试音与生产顺序

先选声线，再做整包。试音不是仅从最顺耳的一句选声音，要覆盖警觉、指令、幽默、痛感、温柔、思考与敌人对照。

1. 两条候选主角声线，先各做 arrival/core 两句。干声、匹配试听音量，比较近距离可信度和情绪变化是否仍像同一个人。
2. 确定方向后制作 `audition-order.json` 中 10 句、每句 3 种演绎，共 30 个片段。敌人分别按各自角色选角，使用各自的 A/B/C 表演指令。四类敌人都必须进入试音，补听受挫/失去防护后的对照句。
3. 为轻击、钩索、重击、断弦各做一个完整声音事件；补两组主角发力。用约 30 秒的实际事件顺序试听组合，先听干声再听场景混音。
4. 选中的表演按同一声线、提示词和表演参考，逐句制作余下台词；身体声单独出片，句尾保留空间。保留原始干声与分层音效。
5. 文件经过命名、来源、音频有效性与重复检查，再接入事件调度。48kHz/24bit WAV 作为建议制作母版；运行副本压缩，不能靠升采样宣称提高音质。
6. 先验收 30 秒片段，再测 10 分钟游玩中的重复、遮挡、疲劳与角色一致性。技术测试和审美验收分别记录。

候选工具路径：可用有表演控制的语音服务做原创声线试音，或者直接由演员按同一导演稿录制。ElevenLabs 的官方文档描述了文字声线设计及表演提示能力，也明确输出需要具体试音验证：[声线设计](https://elevenlabs.io/docs/eleven-creative/voices/voice-design/)、[表演提示](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)。这里没有承诺某个模型一次生成就达到电影质量，没有发起付费任务。

当前会话没有可直接调用的专业配音生成工具。本轮完成的是可交付给声音制作的设计包；继续运行原来的系统朗读脚本，无法验证新的演员式表演方向。

## 8. 接入差异与验收

实现阶段需把“片段清单”和“如何获得音频”解耦：`audio_file` 为空时视为未制作，不以旧系统音色自动补齐。新包采用独立 ID 与目录，保留旧包作对照，不覆盖后失去来源。

已有 `start/retry/guardian/core/finish/exposed` 等事件可复用，但需加入对象有效性、说话者与安全条件。新 `threat_left / encounter_choice / clean_encounter_end / risky_route_landed / low_health_safe / inspect_* / lamp_broken / mimic_missed` 均尚需实现；若关卡没有对应交互，应暂不启用该句，不能随意换成随机播放。

钩索需要明确抓住目标/进入受力阶段的音效事件。发力声要和攻击有效帧/落地冲击同步。`@enemyEvent` 的材质和位置继续用于分层命中。对白状态与游戏状态共同判断，消除遗留 `h-care` 这类未标记长句的例外。

| 验收     | 方法与通过条件                                                                |
| -------- | ----------------------------------------------------------------------------- |
| 声线     | 无配乐干声听测，角色不变声；低声可懂，不是强行压喉                            |
| 表演     | 10 句能分辨主角的情绪以及四类敌人的幽甜、虫性、哀鸣和窃声；不用电子处理也成立 |
| 击打     | 挥空、瓷面、铜壳、破甲可分辨；命中声音跟随实际接触                            |
| 混音     | 普通音量下危险提示不被对白遮挡；耳机、普通扬声器各测一次                      |
| 情境     | 警告不过期，路线提问发生在选择之前；不存在击杀后残留敌人闲聊                  |
| 反复游玩 | 10 分钟内无高频整句复读；三连不出现三个重叠痛呼                               |
