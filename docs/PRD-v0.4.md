版本：v0.4，2026-10-24（Asia/Shanghai）。本次范围是**可从开场玩到结局的单关卡版本**；不是商业发行、完整长篇内容或市场验证完成的声明。上一版风机墓场保存在 [v0.3 PRD](PRD-v0.3.md)。

关联：[开发过程](DEVELOPMENT_LOG.md)、[技术设计](TECHNICAL_DESIGN.md)、[验证](TESTING.md)、[路线](ROADMAP.md)、[素材](ASSETS.md)。

## 1. 产品定义与本次授权

用户提出：横向跑酷过于单调，改为向下和向上穿行；角色可发射钩索，通道里有敌人，技能可击杀敌人；敌人需要好看、有故事感，技能需要有表现力。发散讨论之后，用户授权“现在你来开发完整一版”。

本版选择倒悬钟城：城市悬在深渊之上，守卫继续履行已经失去意义的职责。玩家下潜取回钟心，再借永久锚点、空中连击和改变后的平台向上逃离。

面向愿意练习操作、喜欢机械幻想与氛围探索的电脑玩家。核心价值假设是“移动、战斗与路线选择能够组成一段有个人风格的连续动作”。商业价值、真人初次完成时长和留存仍需观察，不从自动化通关推断。

本版不包含英语教学、语音识别、AI 对话、账号、支付、多人和无尽生成。当前主角沿用蒙面行者，并扩充钩索与战斗姿态；不宣称已落实早期精灵角色设定。

## 2. 一局完整流程

1. 开场选择旅人或无畏，阅读操作指南，进入井口。
2. 向下探索。通过高亮锚点学习牵引与甩出，遇到提灯者和织缆者。
3. 两道实体钟锁阻断直落路线：先击破织缆者，再击破重甲钟卫。普通平台可以穿下，未解锁钟门不能穿下。
4. 在井底对抗末代钟卫。钩住左右红色吊环并抵达，拉断两条钟锁；攻击本体；半血重新封锁，再次破锁后完成战斗。
5. 获得钟心，恢复生命和弦能。三块旧平台坠落，返程守卫出现，黑潮由井底向上推进。
6. 利用永久锚点连续向上，在井口左侧休整灯区域完成旅程。结算时间、分数、最高连击、回声和死亡次数，可重玩。

这是一张手工地图，世界高度约 3,590 单位。HUD 按 10 世界单位显示 1 米，是游戏内的尺度表达。当前路径可被熟练输入快速完成；没有把等待、过场或强制刷怪用作内容长度。

## 3. 输入与连续动作

| 输入        | 行为                                  | 设计目的                 |
| ----------- | ------------------------------------- | ------------------------ |
| A/D、左右键 | 地面移动、空中方向调整、钩索时摆动    | 保留连续动量与落点选择   |
| 空格        | 跳跃、二段跳、贴墙蹬跳                | 在失误后仍有修正机会     |
| 按住 E      | 牵引高亮目标，收绳并保持横向分量      | 以同一动作连通空间       |
| 松开 E      | 甩出，获得向上的释放助力              | 让新玩家能够接续下一锚点 |
| 方向 + E    | 偏向该方向选点，S/下键偏向下方        | 不依赖精细鼠标瞄准       |
| 钩近敌人    | 自动回钩斩，造成 2 点伤害             | 敌人兼具危险与接力用途   |
| J           | 短冷却斩击；可打散近处飞弹            | 战斗不中断移动           |
| 空中 S + J  | 坠星，命中反弹，落地范围冲击          | 把下坠转换成攻击         |
| K / Shift   | 冲刺；W/上键配合上冲，S/下键配合下冲  | 闪避、调整路线           |
| Q           | 断弦爆发，消耗 60 弦能，近身范围伤害  | 在密集战斗中清出空间     |
| S + 空格    | 穿下普通单向平台                      | 主动选择下降时机         |
| Esc / Enter | 暂停、继续；失败后 Enter 从检查点继续 | 保持明确状态             |
| R           | 从头重开本局                          | 练习完整路线             |

钩索最远选择距离 475 世界单位，目标有明确框选。当前是方向辅助选点、牵引、收绳和释放助力的组合；不是完整绳索刚体模拟。基本移动与钩索不消耗弦能。

12 帧位移驱动跑步与新增 8 格动作图集共同呈现动作；抓取、悬吊、斩击、坠星和落地使用不同姿态与短过渡。显示回弹不参与碰撞。仍需真人与动画师判断生成姿态的质量。

## 4. 敌人与叙事

| 敌人     | 视觉与旧职责                                 | 玩法                                               |
| -------- | -------------------------------------------- | -------------------------------------------------- |
| 提灯者   | 窄瓷面、破披风、悬灯；仍在寻找获救者的救援机 | 悬浮巡弋，橙色预警后发射瞄准弹；轻型回钩斩目标     |
| 织缆者   | 瓷质纺锤、六条铜制机械肢；维护空城缆网       | 扇形飞弹，较耐打；第一道钟锁的看守                 |
| 钟卫     | 旧铜钟壳、瓷面和垂摆；守护失去主人的时钟     | 普通斩击在重甲闭合时被挡住，坠星和回钩斩可以破甲   |
| 末代钟卫 | 放大钟壳、双吊索与护罩                       | 两轮破锁、半血变化、扇形钟鸣飞弹；生命归零触发返程 |

故事以开场、章节短句、外形和敌人职责传达。没有制作自由对话、任务树或完整过场；织缆者的实际攻击为扇形弹幕，尚未实现动态织网地形。

## 5. 难度、检查点与资源

- 旅人：8 格生命，较慢飞弹和黑潮，核心守卫 16 点生命。
- 无畏：5 格生命，较快飞弹和黑潮，核心守卫 20 点生命。
- 两档均有检查点、相同操作与核心战规则，开场按 1/2 或点击切换。
- 下潜进入新的休整区时自动记录并恢复生命；界面提示，灯火标识位置。
- 战斗失败：Enter 回到最近休整灯，恢复生命，扣 100 分且不低于 0；已开启普通钟门保留。
- 核心战死亡：复位核心生命和两轮钟锁；返程死亡：保留钟心，重新给出井底逃离机会并重置黑潮。
- R 完全重开，敌人、钟门、回声、钟锁、次数与临时特效回到初始状态。
- 击杀增加弦能、恢复冲刺与二段跳，并形成有时限的连击。三个可选回声各 +500 分并补满弦能。
- 本机保存最多 50 条结算记录，可导出 JSON。无云端上传。

## 6. 场景与反馈

钟城使用绘制的建筑背景、瓷面铜制敌人、雕花平台和材质化角色。可交互锚点、红色钟锁、伤害飞弹与护罩采用清晰的图形表现，背景保持低对比。

反馈包含钩索细链、斩击弧、断弦环、坠星残影、碎片、受击闪光、短命中停顿、轻微镜头震动、前视镜头、雾和尘粒。核心战镜头与平台碰撞、图像注册需要实机检查，不能只凭概念图验收。

宿主页面提供开场、难度、HUD、状态提示、章节、指南、暂停、胜负结算和全屏。合成铃声、风切、金属撞击和低频氛围在用户开始后播放，可以关闭。浏览器隐藏时自动暂停。
