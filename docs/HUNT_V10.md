# 倒悬钟城 v0.10：猎战重构

2026-10-25。当前实现已由 `feat/hunt-combat-v10` 合入 `main`。本文取代 v0.9 的机关、支线、外置钟锁与返程设施设计；三形态 Boss、动作、每次技能刻印及音乐规则保留。验证结果独立记录在 [验收账本](planning/hunt-v10/IMPLEMENTATION.md)。

## 体验目标

玩家靠观察敌人的姿势、选择接近角度、改变高度和安排攻击承诺穿过倒悬旧城。常规遭遇允许绕行，三场精英检验动作理解；取得钟心后沿永久锚点撤离。没有开箱读书、护送、按按钮或修设施的任务链。环境保留成熟的旧金属、石砌拱券、残布和天光，敌人的旧职责通过外形、动作与简短文字传达。

不把普通 J 变成废招：轻敌仍可连击，后背和收势仍可受伤；防止的是持续按 J 把所有敌人锁死。伤害和打断分开判定。护架、低扑、换位与支援要求玩家改变方法，不能用单纯加血和永久霸体代替战斗设计。

## 已落地的敌人

| 敌人 | 轮廓、行为与职责 | 有效应对 |
| --- | --- | --- |
| 悬刃·折翼者 | 残翼与短刃；飞行交叉、二次投刃，争夺高度 | 观察锁向后换高度，收势时追击或射箭 |
| 短锋·决斗者 | 轻甲近身者；护架、撤步、跃踢接扫击；连续受击后撤步 | 普攻起手，观察护架再重斩，追撤步而非站桩连按 |
| 壁弓·逐影者 | 细长弓与墙龛；搭箭、换侧、蹬壁空射 | 用平台遮挡，钩索接近，搭箭时远射 |
| 缚索·收猎者 | 长链武器；投链、横扫、上挑 | 跳过横扫、近身斩断、利用距离脱链 |
| 封脉·伏猎者 | 低伏双刃；绕侧、承诺方向后突袭擒拿 | 改变高度，躲过抓取后反击 |
| 裂甲卫 | 象牙裂甲、旧铜肩甲、巨大盾刃；推进横斩、跃起砸击 | 正面 J、箭和 Q 不能穿过护架；L 破架或绕背。转身有延迟，重劈有收势 |
| 棘背猎兽 | 四足、骨质尖背、低长轮廓；低扑与高弧跃袭交替 | 跳低扑，离开跃袭落点，落地收势追击；扑击途中不能靠轻击无限打断 |
| 缝魂师 | 空袍、瓷面、细长铜臂；单体护架连线与投射攻击 | 优先射击支援者；拉开 300 单位或隔断视线；L 破线；击杀后保护立即失效 |

三类新敌人各有独立透明六姿态图集：待机、移动、蓄势、攻击、收势、受击。图集通过统一落脚线与短暂姿态交叠接入现有渲染。它们不是完整骨骼动画；动作质感仍需实玩反馈继续调整。

## 战斗规则与初始调参

- 裂甲卫基础生命 8；护架仅在正面且没有破架、攻击执行、收势时有效。L 破架窗口 2.6 秒，重斩受击会进入收势。转身等待约 0.55 秒，允许绕背。
- 猎兽生命 4；低扑和跃袭有约 0.62 秒起手（旅人额外 0.12 秒）、0.48 秒实际轨迹、约 0.9 秒收势。一个扑击最多结算一次伤害，碰撞检测覆盖前后位置。
- 缝魂师生命 4；一次保护一个非 Boss 同伴，不回血、不复活、不叠加。破线后 2.6 秒不能重新连接，受伤与施法收势也会暂时停线。
- 决斗者生命 6；持续受击两次后尝试撤步，撤步和承诺攻击期间轻击不能重置全部状态。初始轻击受击停顿约 0.34 秒，重斩可强打断。
- 同时最多两名敌人进入攻击承诺，近身攻击最多一名；新远程支援也纳入预算。起手后段锁定目标，不能按玩家下一帧输入瞬间追踪。
- 钩索可以拉轻敌；重甲、支援护架和猎兽已启动的扑击不接受这种轻敌拉拽。钩索命中也必须通过实际护架/打断判定。
- 普通死亡保留本局已击杀结果和词池，检查点续行清理临时动作、连接、控制与危险；Boss 失败重置完整 Boss 战。

这些数字是当前可玩基线，不是已验证的最佳平衡。困难档改变生命和起手节奏；不额外给技能加冷却。

## 五区十五段遭遇

| 段落 | 区域 | 主要节奏 |
| --- | --- | --- |
| M01–03 | 风钟门 | 无敌门廊练下潜 → 桥头近远夹击 → 空井换高差 |
| M04–06 | 铸钟炉 | 裂甲绕背 → 猎兽空地组合 → 裂甲执刑者 |
| M07–09 | 沉水档案 | 地面伏猎 → 首次支援连线 → 链索、支援与猎兽组合 |
| M10–12 | 碎镜唱廊 | 游走追击 → 双生猎手 → 折翼审判者 |
| M13–15 | 守心机枢 | 支援加重甲 → 心前混合围猎 → 三形态守心者 |

实际布置：40 名普通敌人、4 名精英个体组成三场战斗、1 名三形态 Boss；返程另有 3 名追兵。没有把同一敌人的重试计作新内容。普通段不要求全清，只有 M06、M11、M12 的精英出口受存活状态限制。出口是原建筑平台，不另画操作台、锁盘或巨大任务图标。

- **裂甲执刑者**：16 生命，半血后卸去护架、缩短收势；保持现有攻击承诺，不借变阶段回血。
- **双生猎手**：地面追击和空中投刃接力；距离/视线分离后有短暂配合空档；一人倒下，幸存者缩短再出手等待，不复活伙伴。
- **折翼审判者**：15 生命；俯冲、扇形投刃、双俯冲三种轮换。第二次俯冲有自己的起手，收势后实际飞行换边。
- **守心者**：保留三形态七招、真实空间攻击和阶段变化，移除初始双钟锁。第一次见面即可在收势窗口伤害他。击杀后旧巡逻敌人退场，仅三处返程追兵出现。

检查点自动激活，各区入口与 Boss 前恢复生命。返程路线使用原有固定锚点，不依赖护送、支线或设施开关。猎手手记提供五区故事与八类应对方式，主动查看会暂停。

## 铭文与流畅度

U 蓄箭、L 蓄剑、I 回息、Q 连环剑刀每次有效施放均独立触发单词，Q 答对后才开始出招；失败、超时或放弃取消释放。无技能冷却、无答对后免题次数、无强制凑满 30 词出口。普通攻击、位移和钩索不主动弹题；受控脱身沿用原机制。

题目期间战斗逻辑冻结，表现层继续慢速呼吸、残影和过渡；新 AI 的时钟、护架恢复与连线也冻结。背景音乐继续原音量单曲循环；没有加入对白、钟鼓。答案结束后释放本次动作，不补算冻结期间的攻击。

30 词是一局的可选挑战池。更多敌人提供远射、破架、治疗和终结的真实用途，而不是承诺每种走法必答 30 次。快速绕行或熟练 J 通关可以剩词；应在实玩中记录施放次数、有效命中、未遇词和放弃题，而不是强制补题延长流程。

## 存储、成就与技术边界

- 地图存储版本升至 revision 3。旧 v2 十五段检查点沿用索引，旧机关旗标/支线选择清空；已完成的前序段迁移，不给新精英/成就凭空发奖励。旧 v1 五区检查点映射至 0/3/6/12/14。
- 铭文词池、词册与原有有效成就不重建。旧机关成就退休，新增真实破甲、断线和精英击杀成就；排练不计冒险成就。
- 渲染使用固定可见池，世界碰撞数组完整保留；常驻克隆 121，位于引擎 300 克隆上限之内，瞬时特效仍有独立预算。移除节点/热流/指引图标池和钟锁线克隆。
- 网页宿主负责单词、音乐、存储和 UI，spx 负责动作与敌人。单独 XBuilder `.xbp` 为纯动作工程，不含完整网页能力。
- 验证区分数据单测、响应层固定场景测试、真实键盘整局路线和截图检查。自动通关不等于真人乐趣、30 词自然覆盖或跨设备性能验收。
