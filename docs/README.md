# 文档总目录

更新：2026-10-25。当前产品为主分支 `main` 的 **v0.10 猎战重构**：五区十五段、八类敌人、三场精英、三形态守心者、可选铭文和 18 项成就。

当前规则以 [PRD](PRD.md) 和 [猎战设计](HUNT_V10.md) 为准；项目介绍与启动入口见 [根 README](../README.md)。机关修复、护送、档案底座和外置钟锁已退出当前玩法，旧文档保留作历史参考。局域网联机与其他新方向见 [路线图](ROADMAP.md)，均未因写入文档而实现。
