# WordRunner：英语教学 × 声控跑酷的受众、竞品与避坑研究

研究日期：2026-10-23。依据：公开产品资料、商店数据、公司披露、学术论文和少量可定位的用户反馈。本文提供产品决策建议，不是已经完成的用户验证，也不直接修改 PRD 的交付要求。

## 1. 决策结论

**这个方向有潜在受众，值得继续做小范围验证。现有证据还不足以证明“英语声控跑酷”能持续留住用户、带来英语能力迁移，或形成可盈利的独立产品。**

最值得继续探索的定位是：**让初级学习者在一段短冒险里，用几句听得懂、说得出的英语完成有意义的行动，逐渐减少文字提示。**

需要收紧的地方：

1. “英语 + 游戏 + 声控”已有直接和相邻竞品，不能把这个组合本身作为核心创新。
2. 跑酷提供吸引力和动作反馈；语言任务需要可预期、可等待的表达窗口。
3. 先选择一个人群、一个使用场景、一个可测的学习目标。多个年龄段可以保留为产品方向，不能据此同时验证所有受众。
4. 三天版本最重要的产出应包括用户证据：愿不愿意再开口玩、离开提示后能否使用表达。第二套美术的完成度不能替代这两项验证。

当前判断是“继续验证”，不是“市场已经验证成功”。

**对 WordRunner 的推论：**正面复制大型产品的课程、奖励、跑酷和社交系统，三天内很难获得优势。更合理的切入是做一个足够好的“开口完成情境任务”环节，并证明它比单纯念词换奖励更值得重复使用。

## 4. 首批受众怎么选

以下是基于任务匹配、竞争和验证成本的产品判断，不是人群偏好调查结果。

| 人群 | 与当前概念的匹配 | 主要阻力 | 建议 |
| --- | --- | --- | --- |
| 6–8 岁、基础很少的儿童 | 动作反馈直观 | 阅读、麦克风操作、声音识别和独立理解门槛 | 先不作为首批独立使用对象 |
| **8–12 岁，接触过基础英语、需要短句开口练习的孩子** | 动作词、方位、速度和简单指令容易形成短任务 | 家长要求看到学会了什么；可能只追游戏奖励 | **优先验证的产品人群假设** |
| 13–17 岁学生 | 可以理解更丰富的任务 | 基础动作词容易过浅，需验证其学习目标和可用时间 | 后续验证，不直接套用少儿内容 |
| 成年初学者 / 轻度游戏玩家 | 自己能授权麦克风，容易招募可用性测试 | 六个动作词很快耗尽内容价值；需要不幼稚的呈现 | 可单独做成人方向，但要重设课程深度 |
| 教师 / 机构 | 可以引入固定练习场景 | 多人同时发声、设备管理、课程匹配与采购周期 | 作为后续渠道，不作为三天首发依赖 |

建议的首个使用场景是：**在家、相对安静、有麦克风，每次 3–5 分钟；孩子使用，家长判断是否值得持续使用。**年龄范围是招募假设，筛选时更应关注实际英语基础、阅读能力和游戏操作水平。

用户尚未确认能够接触的试玩群体。若眼下只有成年朋友，可先验证操作和技术，但不能把“成年人觉得有趣”当成儿童市场成立。若成人才是实际可触达渠道，应另建成人初学者假设，避免混合统计。

对儿童人群还要计算真实试验成本：涉及不满 14 周岁个人信息时，个人信息保护法第 28、31 条有敏感信息与监护人同意要求。不要因为原型免费就忽略儿童语音的处理安排；具体上线地区与分发要求需另外核对。[法律原文](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

## 5. 学习效果：能合理承诺到哪一步

### 5.1 学术证据支持尝试，但不能替代本产品实验

- 2026 年一项元分析纳入 12 项定量研究、14 个样本、765 名参与者，发现商业现成游戏辅助词汇学习总体呈正向结果，同时存在较大研究间差异。这里讨论的是词汇，不能扩展成“跑酷提高英语流利度”。本次核验了公开摘要，没有独立重算效应。[论文](https://onlinelibrary.wiley.com/doi/10.1002/jcal.70246)
- 2025 年一项覆盖 99 篇实证文章的综述指出，技术可以通过心理安全和反馈缓解外语焦虑，也可能通过认知负荷等因素增加焦虑。研究偏重高等教育，因此儿童场景仍要实测。[论文](https://www.nature.com/articles/s41599-025-05921-6)
- Habgood 与 Ainsworth 的小学数学实验提示，把知识用于核心游戏操作，可能优于将题目与游戏分开。学习实验为 58 人，自由选择实验为 16 人，研究领域与我们不同，只适合提出设计假设。[原始研究摘要](https://eric.ed.gov/?id=EJ922627)、[作者方法复盘](https://shura.shu.ac.uk/10652/3/Habgood_ZombieDivision_ECGBL2015.pdf)

### 5.2 需要分清四种结果

| 观察到的结果 | 可以记录为 | 不能直接写成 |
| --- | --- | --- |
| 对着文字念出 Jump，系统识别到 | 完成一次有提示口令 | 掌握了该词的使用 |
| 根据不同情境，独立选对并说出指令 | 完成一次情境理解与表达 | 口语流利度提升 |
| 次日去掉文字，在新场景仍能表达 | 初步延迟保持 / 迁移信号 | 已有长期教学效果 |
| ASR 返回正确文本或高置信度 | 识别器返回结果 | 发音标准、口音优劣或专业评分 |

三天最诚实、也最可测的学习目标是：**让原来不会主动使用的少量动作 / 方位短句，在去提示后能被再次正确使用。**

## 6. 跑酷与语音最容易冲突的地方

### 6.1 端到端操作时间比识别延迟更长

需要测量：

```text
看到任务 → 理解情境 → 组织表达 → 说出声音 → 识别完成 → 动作生效
```

PRD 当前的“说完到动作生效 P95 ≤1.5 秒”只覆盖后半段。它不能保证玩家在一个快速逼近的障碍前来得及行动。应按整段过程安排安全距离和等待机制，而不是只优化 ASR 接口耗时。

### 6.2 单次看起来不错的成功率，会在连续关卡里累积问题

**仅作数学示例，不是我们的实测：**假设每次有效口令被正确执行的概率为 90%，六次彼此独立，且任一次失败都会导致整局受挫：

```text
六次都成功 = 0.9^6 = 53.1%
至少一次失败 = 1 - 0.9^6 = 46.9%
```

真实错误可能相关，不能把上式当成实际通关预测。但它说明：即使达到原型工程目标，也应允许重试、延缓障碍、按键接管，不能把识别异常当成英语不合格。

### 6.3 已有反馈也提示“计时 + 阅读”可能制造挫败

Studycat 的一条 2023 年家长评论提到，孩子不会读英文时，跟随歌词点击和限时任务容易令人受挫；开发者回复涉及难度调整及关闭计时 / 生命的计划。这是历史单例，不能代表当前版本或投诉比例，但很适合转成我们的测试用例。[评论与回复所在商店页](https://play.google.com/store/apps/details?id=com.pumkin.fun&hl=en)

**对现有 PRD 的建议：**保留“语言难度和动作难度独立”“语音安全段”“语言错误和动作错误分开记录”。把这些作为核心体验验收，不要为了演示刺激感而取消。

## 7. 不值得优先投入的路线

| 容易走的弯路 | 为什么会浪费投入 | 更值得先做的事 |
| --- | --- | --- |
| 一开始覆盖儿童、青少年、成人 | 内容深度、审美、操作、付款者不同，不能用一个满意度平均数判断 | 一个人群、一种场景，先证明重复使用 |
| 六个动作词无限重复 | 玩家可能学得很快，后续只剩操作习惯 | 少量短句的情境变式与去提示复习 |
| 每个紧急操作都靠开口 | 表达和识别耗时，与反应窗口冲突 | 预告式语音任务、宽松窗口、按键接管 |
| 念任意英语就补能量 | 口头活动可能与词义理解脱节 | 说出的意思决定具体路线或场景动作 |
| ASR 一错就扣命 | 技术问题变成学习失败感 | 技术异常不罚，明确提示、可重试 |
| 用 ASR 分数做发音排名 | 识别结果不能代替有效发音测评 | 先报告是否理解并完成任务，不做口音排名 |
| 先做开放世界、AI 自由对话、多语言 | 内容审校和技术边界迅速扩大 | 固定任务、短句白名单、可核验反馈 |
| 把两套精细美术当成市场验证 | 美术偏好回答不了学习价值与复玩 | 一个精细主场景，第二风格先做选择测试；是否降级需调整 PRD |
| 只追时长、连胜、排行榜 | 这些指标无法说明词句掌握和次日主动练习 | 去提示表达、技术挫败率、主动复玩 |
| 先搭支付、账号、学校系统再找用户 | 购买理由与触达渠道还未明确 | 先观察目标用户行为，再决定销售形式 |
| 用朋友的夸奖证明市场 | 礼貌偏差、样本不匹配、新鲜感都可能混在一起 | 记录不提示情况下的选择和真实重访 |

现 PRD 名义上有 2 主题 × 3 英语等级 × 2 动作难度 = 12 种配置；若再检查按键、语音、混合接管三条路径，就是 36 种组合。它不是必须写 36 个完整测试的规定，也不是已完成的测试数，而是提醒我们：多维选择会扩大内容和验收工作。

## 8. 可以保留跑酷，同时改善学习匹配

建议将 90 秒冒险组织为：**短动作路段 → 看清场景并听到任务 → 宽松语音窗口 → 表达推动动作 → 很短的反馈 → 进入下一段。**

第一轮只围绕三个语言关系做情境，示例如下，最终难度须由前测决定：

| 学习目标 | 游戏里的表达示例 | 场景反馈 | 去提示后的检查 |
| --- | --- | --- | --- |
| across | Jump across the gap. | 跨越缺口 | 换一处缺口，能否自行组织表达 |
| under | Go under the bridge. | 从低处通道经过 | 换一个已知物体，能否判断并说出 under |
| before | Stop before the gate. | 在门前停下 | 换目标点和布局，能否在正确位置停下并表达 |

句中的物体词必须是已知词或已教学内容，不能把“不认识新名词”误判为不理解方位。评估时不能总让画面只剩唯一可选动作，否则玩家可能凭障碍形状猜对，根本没有理解英语。

跑酷成功、语言理解正确、是否看过提示、是否由按键接管应分别记录。键盘通关依然成立，但不能生成虚假的口语掌握记录。

这里的创新机会是“语义、行动、宽容反馈、逐步去提示”的组合体验，仍然只是待验证的差异化假设；不应宣称全球首创或已经形成竞争壁垒。

## 9. 三天内怎样取得有用证据

以下数量和阈值是本项目建议的决策规则，不是行业基准，也不保证统计显著性。试玩邀请和任何付费操作均尚未执行。

### 第一阶段：先排除技术问题

沿用 PRD 的 5 人 × 6 指令 × 2 次工程测试，并单独记录噪声、拒绝权限、断网、迟到结果和按键接管。成年人的技术试验不代表儿童声学表现；最终面向孩子时，须补目标年龄的识别验证。

把失败分成“表达含义不对”“说对但未识别”“识别对但动作没执行”“动作执行但碰撞失败”。不分原因的总成功率会误导后续决策。

### 第二阶段：8–12 组目标家庭的形成性试玩

建议以 12 组为计划，每组约 15 分钟，合计约 3 小时；招募不足应报告实数，不补造比例。家长和孩子分开提问。

1. 前测少量目标表达，避免 Jump 等本来就会的词造成虚假提升。
2. 试玩同一场景的两种节奏：连续限时语音、允许等待的语音段。使用配置切换，避免制作两套游戏。
3. 平衡两种节奏的先后顺序，使用难度相近的不同表达集，减少第二次天然更熟悉的影响。
4. 去掉提示后检查理解与表达；记录用不用语音、主动再玩、停下原因。
5. 提供自由选择的一局，不用额外金币或奖励诱导“再玩一次”。

**建议的继续信号：**12 人中至少 8 人不靠研究者提示完成入门，至少 8 人愿意再玩；这些是设计门槛，不能转换成全市场的 67% 转化率。

如果大多数用户能说出来，却仍更愿意关闭声音，优先检查声控的实际价值和节奏。若主要卡在识别，就先修识别，暂时不能归因成没有市场。

### 第三阶段：隔天保持与真实选择

- 记录 24–48 小时内是否主动回来，以及回来后是否继续使用语音。一次试玩当场重开不是 D1 留存。
- 对前测不会的表达，使用新布局、减少文字提示再次检查；由人工核对含义，ASR 只记技术结果。
- 可暂设“至少 8/12 人能独立使用至少两个前测不会的目标表达”为内容继续信号；若前测几乎全会，应更换任务，不能报告学习增益。
- 家长访谈问最近使用 / 放弃过什么产品、上一次为何付费、能接受什么使用时长，以及怎样的结果才值得继续。不要只问“喜欢吗、愿不愿意付费”。

三天内通常无法完成真正 D7 留存验证；应把第 7 天复访列为后续计划，不能提前宣称形成习惯。要证明比普通练习更有效，后续还需要等内容、等练习量的对照设计，并根据试点方差确定样本量。

### 建议的停损规则

| 发现 | 下一步 |
| --- | --- |
| 识别错误主导挫败 | 改识别和窗口，暂停新增场景 |
| 声控可靠，但玩家持续回避开口 | 改任务的必要性和反馈；不要靠奖励强行解释为用户喜欢 |
| 玩得开心，但次日不会使用目标表达 | 重做教学和复习设计；停止宣传学习效果 |
| 孩子愿玩，家长看不到价值 | 改学习结果呈现和内容目标，不先做付费墙 |
| 只有朋友礼貌评价，没有主动复玩 | 扩充目标样本，暂缓投放 |

## 10. 商业方向与投入顺序

**短期优先验证家庭端的小内容产品。**付费理由可以围绕经过审校的分级情境、持续复习和可理解的学习记录。先验证这一理由，再决定主题包买断还是持续订阅；单个 90 秒原型不足以支持一整年的订阅承诺。

竞品既有订阅，也有买断，说明形式本身不是答案。若使用按分钟收费的云 ASR，还要核算长期服务成本，不能拿一次性购买收入假设能覆盖无限语音使用。

```text
每位付费用户的周期贡献
= 实收收入
- 渠道与支付费用
- 语音、模型、带宽和存储成本
- 内容维护、退款与支持成本分摊
```

没有真实使用时长、留存和付费数据前，不给本产品预测 LTV、CAC 或利润。三天中可展示清楚的后续内容范围和试验价格，观察是否主动预约；预约、口头愿付费和真实付款要分开记录，不能混为付费率。

下一步投入顺序建议：

1. 目标用户与可招募渠道。
2. 真人语音 → 动作闭环及可等待的节奏。
3. 一个完成度高的场景、少量有意义的表达。
4. 去提示复习、次日检查、家长可读结果。
5. 得到重复使用证据后，扩充第二主题、内容包与商业系统。

多主题、多个年龄段和丰富动作仍可作为路线图。是否把其中部分从当前 P0 调整为后续事项，需要据这份研究评审 PRD，不能一边缩减一边宣称原要求已经完成。
